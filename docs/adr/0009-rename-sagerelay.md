# 改名「建议驿站」（SageRelay）：官方文书的接力驿站

用户在创建 GitHub 仓库时将英文项目定名 SageRelay，并给出中文项目名「建议驿站」，取代 ADR 0008 的「一枝春」。驿站是中国古代官方文书接力传递的节点——与项目"收录官方指南、附上出处、一站站递送给用户"的本质完全同构，且保留了项目早期代号 advice（建议）的血统；英文 SageRelay 中 Sage（权威/智者）对"官方权威"，Relay（接力）对"驿站传递"。改名发生在上线前，仅涉及文案替换，成本最低的时机。

## Consequences

- GitHub 仓库为 yshuai/SageRelay，工作流按仓库名自动计算 Pages 子路径 base，改名不影响部署配置。
- 站内文案与术语表已全量替换；ADR 0008 退役保留为历史记录。
