# 白名单例外：市场化投诉平台的显式标注收录

用户要求收录黑猫投诉等消费者投诉平台。黑猫投诉（新浪旗下）为**商业化平台**，与 ADR 0002"白名单外一律不收"及"不背书"红线存在冲突。经权衡，作为**显式例外**处理，而非打破白名单：

1. **收录形态**：不单独成篇，置于《投诉举报渠道全景》页内"市场化平台"小节，与官方渠道（12315/12345/12321/12377/互联网+督查）**物理分区**。
2. **标注义务**：页首 danger 框 + 条目内重复声明"非官方、无行政强制力、不背书其处理结果"；官方渠道永远排在前面。
3. **不背书的边界**：黑猫投诉等平台的处理结果不作为本站任何词条的引用来源；它们只出现在"维权路径"语境，不进入内容溯源链。
4. **扩展约束**：此类例外平台仅限"投诉/曝光"这一种社会监督功能；测评、种草、榜单类商业内容永不收录（守住 ADR 0002 反带货红线的本意）。

同页一并收录官方举报矩阵（12345 综合热线、12321 骚扰信息、12377 网络违法信息、互联网+督查）， filling 此前只有 12315 单点的空白。
