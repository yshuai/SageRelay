# 行动清单：可执行内容以逐条溯源为前提

用户希望词条从"地图式导读"升级为可直接执行的整理（提取、概括、给出可实行的办法，不满意的用户再去原文核对）。为守住"不生产医疗科普"的合规红线（ADR 0004、0006，2025 年网信办《关于规范"自媒体"医疗科普行为的通知》），确定如下边界：

1. 行动清单的每一条都必须能在官方原文中找到对应原句或数字，并标注出处章节；语言可以口语化，数字与结论不得改动，不跨文件组合。
2. 唯一例外是显式标注的「本站提示」，仅限中性工具性内容（量具使用、看标签方法等），永不涉及医学判断。
3. 生产流水线：pdftotext 提取官方 PDF 全文 → AI 结构化整理 → 人工逐条对照原文核验，`reviewed` 字段控制发布状态。
4. 免责声明同步升级："本页所有建议均整理自官方文件原文、逐条可溯源；本站不构成诊疗建议，与医生的治疗方案冲突时，以医嘱为准。"

词条新结构：速览卡 → 行动清单（买/做/吃/动/测）→ 常见误区（仅原文有对应告诫时）→ 分地区食谱指引 → 原文链接与溯源。

## 修订（上线后用户反馈）

- **发文字号字段整体取消**：用户核验时"找不到出处"——转述而来的字号无法自证，且原文页自带该信息。本站不再转述任何无法被用户直接核验的字段。
- **出处一律改为跳转链接**：官方 PDF 托管为本站镜像（`web/public/guides-pdf/`，政府公文属公共领域），行动清单/速览卡的"出处"是 `#page=N` 直达原文对应页的链接；纯文字章节号（如"三(一)"）因用户无法定位而废弃。页码由 PyMuPDF 在提取时计算。
