# 语料库公开开源：透明即信任

决定将代码与语料库以公开仓库运营（这也是 GitHub Pages 托管的前提）：任何人可查看、可提 issue 纠错。信任来自可验证——每处改动可追溯，比"闭源但自称严谨"更符合本项目的立身之本。

授权边界：政府公文等原文属公共领域，标注来源即可使用；项目自产内容（导读、结构化整理）以 CC BY-NC-SA 4.0 授权——允许署名转载与非商业再加工，禁止被拿去做商业背书。纠错 issue 必须附白名单来源链接，否则不受理，与来源白名单原则一致。

## Consequences

- 内容会被原样搬运。接受：搬运者带不走"持续更新 + 社区纠错 + 版本受控"这项真正的服务。
