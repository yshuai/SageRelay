# 仅网站单端：放弃小程序选项

用户曾计划未来上线微信小程序，在定名阶段决定放弃。本项目定为纯网站单端（静态文档站），不规划小程序或其他端，构建管线只产出网页，无需预留多端 JSON。

调研中核实、且对网站仍然适用的约束，留存如下：

- **2025 年 8 月网信办《关于规范"自媒体"医疗科普行为的通知》**：未经医疗资质认证，不得生产发布专业医疗科普内容。这使"导读只做地图、不新增医学论断、一切以原文为准"从编辑风格升级为合规红线。
- 名称含"官方/国家/权威/中国"等字样在各内容平台需资质或授权才能使用；命名须规避，并兼顾输入法连打（现成词/成语）与 SEO。

（本文取代定名过程中曾短暂记录的"网站先行、小程序后置"多端方案。）
