# 官方查询导航域启动：只导航、只教用，不代查

用户要求延伸到部委下属单位与官方查询页面（如卫健委政务服务平台 zwfw.nhc.gov.cn 的查询频道）。决定引入第四种内容形态**查询页**，并启动"官方查询"域。

边界（本域的立身之本）：
1. **只导航 + 只教用**：官方入口唯一权威链接、查询步骤、结果怎么读、避坑要点；不代查、不缓存/转存查询结果、不聚合第三方镜像入口。
2. **入口腐坏对策**：每个查询页标注"入口以部委官网为准"，纳入半年核查节奏；链接失效立即修。
3. **白名单扩展**：部委直属单位与部委运行的政务服务平台归一级来源（健康中国官方平台、国家食品安全风险评估中心、国家癌症中心/心血管病中心、卫健委政务服务平台等）；中国疾控中心维持二级。

首批四篇（家庭防坑四大件）：化妆品备案/注册查询（NMPA——注意化妆品不在卫健委政务平台，属药监局）、药品批准文号查询（NMPA）、医疗机构与执业医师查询（卫健委政务平台"查信息"频道，已浏览器实测含执业医师/执业护士/辅助生殖机构/爱婴医院等）、保健食品注册备案查询（市场监管总局特殊食品信息查询平台）。

事实核查记录：zwfw.nhc.gov.cn/cxx/ 实测为"查信息"频道（浏览器验证），**不含化妆品查询**——化妆品属药监局体系，词条如实分流，不做迁就。
