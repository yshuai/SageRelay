# 定名「一枝春」：以「聊赠一枝春」承载借花献佛的项目本质

> **已退役**：项目于上线前改名为「建议驿站」（英文 SageRelay），见 [ADR 0009](./0009-rename-sagerelay.md)。本 ADR 保留为命名过程记录。

命名历经七轮，约束逐步沉淀为：不含"官方/国家/权威/中国/第一/最"等平台敏感字；不占常用成语；输入法拼音可连打（现成词或自然语素组合）；SEO 上"品牌词 + 病名/产品"组合无竞争；有典籍出处；含蓄不直白。最终取陆凯《赠范晔》"江南无所有，聊赠一枝春"——官方种的花，本站折一枝、附上出处、寄给用户；"一枝春"后为梅花雅称并入词牌，典籍有据而不占成语。被否决的方向：直述型（国家食养指南库）、口语官方梗（官方怎么说）、成语占用（白纸黑字/心里有谱）、新造典籍风（食养正要/格致正要——冷感过重）、直白化用（借花献你——过于直白）。

## Consequences

- 全网查重（同名图书/公众号/商标）与域名注册尚未完成，属开建前待办；品牌资产积累后改名成本上升，应尽早完成。
