# 来源白名单增设第三级：权威医疗机构与认证医生

用户计划在后续阶段引入第三方权威医院医生的科普内容，与 ADR 0002 的"医院公众号一律不收"冲突，故以本 ADR 取代该条。白名单改为三级：

- **一级**：国务院部委及直属机构（卫健委、疾控局、标准委、市场监管总局等）。
- **二级**：官方指定专业机构（中国营养学会、中国疾控中心、中国消费者协会）。
- **三级（新增，后置启用）**：权威医疗机构（三甲医院等）的官方科普，以及经资质认证的医生个人科普。

三级来源的收录护栏：

1. 资质必须可核验：机构实名、医生真实姓名 + 职称 + 所在机构，页面标注来源级别与作者。
2. 以"链接 + 摘要 + 标注"为主，不整篇转载——医生科普享有著作权，与政府公文不同。
3. 与一级来源冲突时，以一级来源为准，并显式标注分歧。
4. 启用时点后置：待首批词条闭环（发布 → 被搜到 → 收到纠错）后再评估，遵守"一次只扩一个域"的纪律。
