# 建议驿站

> 驿站，是古代官方文书接力传递的节点——我们收录官方指南、附上出处，一站站寄给需要的人。

**建议驿站（SageRelay）**是非官方的科普汇编站：把国家权威部门的指南、标准、数据与查询服务，整理成**可溯源、受版本控制**的页面。不做自创健康论断，每个结论都能点进原文核对。**非官方 · 不带货 · 不构成诊疗建议**。
