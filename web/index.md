# 建议驿站

> 驿站，是古代官方文书接力传递的节点——我们收录官方指南、附上出处，一站站寄给需要的人。

**建议驿站（SageRelay）**是一个非官方的科普汇编站：把国家权威部门发布的指南文件，整理成可溯源、受版本控制的词条。我们不做任何自创的健康论断，你看到的每个结论都能点进原文核对。
