# 化妆品备案/注册查询 · 防假货第一步

::: warning 待核验
本页由 AI 依据官方平台公开信息整理，查询步骤请以平台实际页面为准；平台入口改版时以药监局官网为准。
:::

> **官方入口**：国家药品监督管理局[数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)（选择"化妆品"分类）。**注意：化妆品查询在药监局体系，卫健委政务服务平台不提供此项。** · 一级来源

## 速览卡

在中国**合法销售的化妆品都有备案号或注册号**。查不到 = 要么是三无产品，要么信息造假。这是防假货的第一道闸。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [NMPA 数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)，选"化妆品" |
| 2 | 按产品类型选子库：国产普通化妆品（备案）、进口普通化妆品（备案）、特殊化妆品（注册，如染发、祛斑美白、防晒、防脱发） |
| 3 | 输入产品名称或备案号（包装上有"备案号：国妆网备字/G妆网备字XXXX"或"国妆特字XXXX"） |
| 4 | 核对结果里的**产品名称、备案人/生产企业、状态**与手里产品是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 查到且状态正常 | 备案/注册真实有效（[数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)） |
| 查不到 | 三无或信息造假，**不要用** |
| 备案人/企业与包装不一致 | 可能套号，谨慎 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "药妆""医学护肤品""械字号面膜更安全" | 我国不承认"药妆"类别，化妆品宣称药用属违规宣称（[药监局科普](https://www.nmpa.gov.cn/datasearch/home-index.html)） |
| "进口大牌但查不到" | 进口化妆品同样必须备案/注册，查不到就是问题 |
| 【本站提示】看包装备案号与平台结果逐字符核对，别只搜品牌名 | — |
