# 买药防坑 · 药品比价与追溯码

::: warning 待核验
本页由 AI 会话信息整理；比价与追溯码功能在**各地分批上线**，以国家医保服务平台 App 与当地医保局口径为准。
:::

> **官方入口**：[国家医保服务平台](https://fuwu.nhsa.gov.cn/) App（药品比价、追溯码扫码在部分/多数地区已上线，待核验）；各地医保局小程序。· 一级来源

## 速览卡

买药两把官方尺子：**比价**——同一通用名药品，附近药店/医院卖多少钱一目了然，别当"冤大头"；**追溯码**——药盒上的追溯码扫码验明"出身"，专防**回流药**（从医保套出来的药再倒卖回市场，储存运输无保障）。

## 行动清单

| 怎么做 | 出处 |
| --- | --- |
| 买药前：[国家医保服务平台](https://fuwu.nhsa.gov.cn/) App 查**药品比价**（输入通用名，比附近药店/医院价格） | 待核验 |
| 拿到药后：医保 App **扫药盒追溯码**——显示"已售/首次销售"等信息；**被扫过多次的码 = 高度疑似回流药**，可拒收并举报 | 待核验 |
| 认准**集采中选药品**：国家集采让同成分药价大幅下降，医院/药店有售，效果一致性有评价（待核验） | 国家医保局 |
| 网购药品：平台需展示《药品网络交易服务备案》资质；**处方药必须凭处方** | 药监局规定 |

## 避坑要点

| 骗局话术 | 官方事实 |
| --- | --- |
| "高价回收药品/医保卡套现" | 回收倒卖医保药品**违法**，且这些"回流药"来源贮存不明——不卖不买 |
| "微商代购国外特效药" | 无批准文号的境外药品按假药论处，见[药品批准文号查询](/query/drug) |
| "比价麻烦，反正医保报" | 医保基金是全家的钱袋，价格差最终影响报销池与个人自付 |
| 【本站提示】慢病长期用药：结合[慢病食养词条](/guides/hypertension-2023)把生活方式干预做足，用药方案永远听医生的 | — |
