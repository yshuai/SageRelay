# 溯源码查询 · 农产品与婴幼儿配方乳粉的"前世今生"

::: warning 待核验
本页由 AI 会话信息整理；农产品追溯平台入口对自动化访问返回 403（平台存在），查询请以农业农村部官网入口为准。
:::

> **官方入口**：农业农村部[国家农产品质量安全追溯管理信息平台](http://www.qsst.moa.gov.cn)（扫码查履历）；工信部[食品工业企业追溯平台](https://foodcredit.miit.gov.cn)（重点覆盖**婴幼儿配方乳粉**追溯）。· 一级来源

## 速览卡

带**溯源二维码**的农产品和婴幼儿配方乳粉，扫码就能看到产地、生产、检验、流通信息——"从农田到餐桌"的官方履历。给孩子买奶粉、给老人买粮油，认准可追溯的产品并顺手扫码验证。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 找到包装上的**追溯二维码**（或追溯码数字） |
| 2 | 用微信"扫一扫"扫码，或到对应平台输入追溯码：农产品走[国家追溯平台](http://www.qsst.moa.gov.cn)，婴幼儿配方乳粉走[工信部追溯平台](https://foodcredit.miit.gov.cn) |
| 3 | 核对：产地/厂家、生产日期、检验信息与包装是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 履历完整且与包装一致 | 可追溯产品（[追溯平台](http://www.qsst.moa.gov.cn)） |
| 扫码无结果或信息对不上 | 谨慎购买，向商家索要进货凭证 |
| 平台查不到但商家称"有机/绿色" | 让商家出示认证证书编号，去认证机构官网核 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "自家散养纯天然，比可追溯的更好" | 无溯源无检验的无证产品风险自担，追溯体系正是官方给的验证工具 |
| 【本站提示】溯源码只能证明"履历真实"，不能替代[抽检记录](/query/food-spot-check)——两个都查更稳 | — |
