# 公积金查询 · 余额、提取与继承

::: warning 待核验
本页由 AI 会话信息整理；公积金提取细则**各地不同**，以当地公积金中心规定为准。
:::

> **官方入口**：微信/支付宝搜索"**全国住房公积金**"小程序（住建部指导）；各地公积金中心官网/APP；热线 **12329**。· 一级来源

## 速览卡

公积金不只是买房才用得上：**租房、退休、大病等情形可依法提取**；职工身故后，账户余额由**继承人提取**（《住房公积金管理条例》，待核验）——这是很多家庭漏掉的一笔钱。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开"全国住房公积金"小程序，实名登录 |
| 2 | **查余额与缴存记录**：账户明细一目了然 |
| 3 | **提取**：按情形走当地中心线上/线下流程（购房、租房、退休等） |
| 4 | **身故继承提取**：继承人凭死亡证明+关系证明，到当地公积金中心办理 |

## 结果怎么读

| 情形 | 说明 |
| --- | --- |
| 在职正常缴存 | 可查缴存单位与月缴存额（[小程序](https://www.mohurd.gov.cn/)） |
| 退休 | 可全额销户提取 |
| 身故 | 继承人依法提取余额；多人继承需协商或公证——细节问 12329 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "公积金代提代办，收手续费" | 符合条件的提取本人即可办、**不收任何手续费**，中介多为诈骗 |
| "离职就能立刻全额提现" | 异地转移接续与提取规则各地不同，先问 12329 再签任何协议 |
