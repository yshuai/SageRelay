# 导游与旅行社核验 · 出游前查资质

::: warning 待核验

> **官方入口**：文化和旅游部[全国旅游监管服务平台](https://mr.mct.gov.cn)。· 一级来源

## 速览卡

合法导游持有**电子导游证**，合法旅行社有**经营许可**——都可以在全国旅游监管服务平台核验。跟团游、请"私人向导"、报"低价纯玩团"之前，先查一眼资质，防黑导游防强制购物。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[全国旅游监管服务平台](https://mr.mct.gov.cn) |
| 2 | **查导游**：输入导游姓名或导游证号，核对**电子导游证**有效期与所属机构 |
| 3 | **查旅行社**：核对经营许可与经营范围（出境游需额外资质） |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 导游证在有效期内、机构一致 | 正常（[监管平台](https://mr.mct.gov.cn)） |
| 查无此人/证已过期 | "黑导游"，向 12345 或文旅部门举报 |
| 旅行社无出境游许可却招出境团 | 违规经营，慎交定金 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "低价纯玩，到了再补一点费用" | 不合理低价团是强制购物的固定剧本；资质+合同+行程单三样都核 |
| 【本站提示】导游"现场换人"时，要求出示电子导游证当场扫码核验 | — |
