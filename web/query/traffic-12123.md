# 交管 12123 · 违章/驾照/车辆检验一站办

::: warning 待核验
本页由 AI 会话信息整理并经浏览器核验入口可达；业务细则以 APP 内指引与当地车管所为准。
:::

> **官方入口**：公安部交管局 **交管 12123** APP（官方应用商店）；[公安部互联网交通安全综合服务管理平台](https://gab.122.gov.cn/)（已核验可达）；服务监督 **12328**。· 一级来源

## 速览卡

有车/有照家庭 90% 的车管业务都在这一个 APP：**处理违章、期满换证、检验预约、补牌补证、事故快处**，还有**电子驾照**与**电子检验标志**（全国通用，不用贴车窗）。

## 30 秒操作步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 下载"交管 12123"APP，实名注册（刷脸） |
| 2 | **违章**：首页"违法处理"——查询、在线缴罚（记分可学法减分，待核验） |
| 3 | **驾照**：期满前 90 天内 APP 换证（先体检或到医院体检信息直传） |
| 4 | **车辆检验**：APP 预约检验站；6 年内免检车直接申领电子检验标志 |
| 5 | 丢牌丢证：APP 补换，邮寄到家 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 违章记录与照片一致 | 在线缴罚即时生效（[交管平台](https://gab.122.gov.cn/)） |
| 记分接近 12 分 | 谨慎驾驶 + 关注"学法减分"当地是否开通 |
| 检验有效期即将到期 | 提前预约，脱检上路会被处罚且保险可能拒赔 |

## 避坑要点

| 骗局话术 | 官方事实 |
| --- | --- |
| "代处理违章，包消分" | 处理需**人脸认证本人办理**，黄牛代处理属违法且信息泄露 |
| "内部渠道快速年检" | 检验一律 APP 预约 + 检测站排队，无内部渠道 |
| 【本站提示】买二手车：先查抵押/查封（[执行信息公开网](/data/official-databases)）与违章记录，再过户 | — |
