# 医疗器械查询 · 家用设备也认"注册证"

::: warning 待核验
本页由 AI 依据官方平台公开信息整理，查询步骤请以平台实际页面为准；入口改版时以药监局官网为准。
:::

> **官方入口**：国家药品监督管理局[数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)（选"医疗器械"分类：国产/进口，按一类、二类、三类分级）。· 一级来源

## 速览卡

家用血压计、血糖仪、体温计、隐形眼镜、医用口罩……只要宣称"诊断或治疗"用途，就必须有**医疗器械注册证编号**（"械注准/械备案"开头）。朋友圈卖的"械字号面膜"多数是偷换概念——真正的械字号是医用敷料类器械，查注册证一验便知。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [NMPA 数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)，选"医疗器械" |
| 2 | 按产品选子库（国产/进口；一类备案、二三类注册），输入产品名称或注册证编号 |
| 3 | 核对：**产品名称、注册人/生产企业、有效期、适用范围**与产品是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 注册证在有效期内、信息一致 | 正常（[数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)） |
| 查无此证 | 无证"医疗器械"，不要买不要用 |
| 号称械字号但查到的是"妆字号" | 偷换概念，按化妆品管理、不得宣称疗效 |
