# 养老机构查询（养老地图）· 给爸妈找照护

::: warning 待核验
本页由 AI 会话信息整理并经浏览器核验入口可达；查询步骤请以平台实际页面为准。

> **官方入口**：民政部[全国养老服务信息平台](https://yanglao.mca.gov.cn)（"养老地图"）。· 一级来源

## 速览卡

全国养老机构、社区养老服务机构和助餐点的点位信息集中在一张官方地图上——给爸妈找养老院、找社区食堂，**先在官方地图上圈候选**，再实地考察，避开没有登记备案的"黑机构"。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[全国养老服务信息平台](https://yanglao.mca.gov.cn) |
| 2 | 定位城市/小区，浏览"**养老地图**"：机构、社区照护、助餐点分类展示 |
| 3 | 点开候选机构看**备案信息、服务内容**，记下 2～3 家实地走访 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 地图有登记、信息完整 | 已备案机构（[养老地图](https://yanglao.mca.gov.cn)） |
| 实地看着不错但地图查无 | 未登记备案——无备案即无监管兜底，慎选 |
