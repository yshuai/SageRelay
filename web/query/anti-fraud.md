# 全家反诈体检 · 国家反诈中心 + 96110 + 一证通查

::: warning 待核验
本页由 AI 依据公安部、工信部公开宣传口径整理；"一证通查"入口已浏览器核验可达，APP 与热线功能以官方发布为准。

::: danger 使用须知
电信诈骗是当前家庭财产损失最大、最高频的坑。本页四步做完约 15 分钟，**建议每个家庭每年做一次**——尤其给父母做。
:::

## 速览卡（三道防线 + 一个底查）

| 防线 | 是什么 |
| --- | --- |
| **国家反诈中心 APP**（公安部刑侦局） | 开启来电/短信/APP 风险预警——诈骗电话打进来会拦截提醒 |
| **96110** | 反诈预警劝阻专线——**这个号码打来的务必接**，是警察在阻拦你转账 |
| **12381** | 工信部涉诈预警劝阻短信——收到即高危 |
| **一证通查** | 查**名下**到底有几张电话卡——防止被冒名办卡用于诈骗 |

## 四步行动清单

| 步骤 | 怎么做 | 出处 |
| --- | --- | --- |
| 1 | 全家手机安装**国家反诈中心 APP**（官方应用商店，开发者"公安部刑事侦查局"），开启来电预警权限 | 公安部发布口径 |
| 2 | 告诉父母：**96110 打来的必须接**；收到 **12381** 预警短信立即停手核实 | 工信部/公安部 |
| 3 | [一证通查](https://getsimnum.caict.ac.cn/)（已核验可达）：凭身份证查名下电话卡数量——多出来的卡立即去运营商销户（互联网账号查询为 2.0 服务，域名 getaccount.caict.ac.cn 经人工浏览器访问确认有效） | [信通院平台](https://getsimnum.caict.ac.cn/) |
| 4 | 给父母做一次"骗局考试"（见下表），让他们复述"三个凡是" | 公安部宣传口径 |

## 高发骗局速查表

| 骗局 | 一句话拆解 |
| --- | --- |
| 冒充公检法 | 真警察**不会**电话办案、不会要你转账到"安全账户"、不会让你保密 |
| 刷单返利 | 先给甜头后宰杀，所有刷单都是诈骗 |
| 虚假投资理财（杀猪盘） | 网友/导师带你"稳赚"的平台 = 你看到的数字都是画的 |
| 冒充电商客服退款 | 绕开平台私下"退款理赔"的都是诈骗，退款只走原平台 |
| 冒充领导/熟人 | 换号、AI 合成声音——当面或回拨本人常用号码核实 |
| AI 换脸视频通话 | 视频也能造——**看脸不如验证**：让对方做指定动作、问只有本人知道的事 |

**"三个凡是"铁律**（教给父母）：凡是要求**转账到安全账户**的都是诈骗；凡是要求**屏幕共享/提供验证码**的都是诈骗；凡是**网上认识就带你投资**的都是诈骗。
