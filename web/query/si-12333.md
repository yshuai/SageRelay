# 国家社会保险公共服务平台 · 查权益算养老金做认证

::: warning 待核验

> **官方入口**：人力资源社会保障部[国家社会保险公共服务平台](https://si.12333.gov.cn/)（另有"电子社保卡"App/小程序、12333 热线）。· 一级来源（[入口已核验可达](https://si.12333.gov.cn/)）

## 速览卡

社保三件最常办的事都在这一个官方平台：**查权益**（缴费了多少年、账户多少钱）、**算养老金**（官方测算器，城镇职工和城乡居民两个版本）、**待遇资格认证**（领养老金的每年刷脸一次——不做会被停发）。配套阅读：[养老金身故后怎么办](/social/pension-after-death)。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[国家社会保险公共服务平台](https://si.12333.gov.cn/)（或电子社保卡小程序，登录需实名） |
| 2 | **查权益**：社保查询 → 个人权益记录（缴费年限、个人账户余额） |
| 3 | **算待遇**：养老金测算 → 选"城镇职工"或"城乡居民"版本，按提示填参数 |
| 4 | **做认证**：领取待遇资格认证 → 刷脸，老人由子女用自己手机协助完成 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 权益记录与实际缴费一致 | 正常（[社保平台](https://si.12333.gov.cn/)） |
| 测算结果偏低 | 检查缴费年限是否漏记，可向 12333 反映核实 |
| 认证显示"已完成" | 下一年度仍需再认证；未按期认证会**暂停发放**，补认证后恢复补发 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "社保局短信：点链接补认证，否则停发" | 官方认证只在官方 App/平台刷脸，**不会索要短信验证码、不会发链接**——典型诈骗 |
| "代办公益性补缴养老金，收费办理" | 补缴政策有明确规定，代缴中介多为诈骗，问 12333 |
| 【本站提示】父母不会用手机的，子女在"电子社保卡"里添加亲情服务代为认证 | — |
