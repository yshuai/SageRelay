# 考证防坑 · 证书真伪与国家目录核对

::: warning 待核验
本页由 AI 会话信息整理并经浏览器核验入口可达；具体目录项数与细则以人社部最新文件为准。

> **官方入口**：人社部[技能人才评价证书全国联网查询](http://zscx.osta.org.cn/)（职业技能等级证/职业资格证）；[中国人事考试网](http://www.cpta.com.cn/)（专业技术人员资格考试报名/成绩/证书）。· 一级来源（[两入口已核验可达](http://www.cpta.com.cn/)）

## 速览卡

判断一张证有没有用，**第一步不是查真伪，是查它在不在《国家职业资格目录》里**——目录内的才叫国家职业资格（准入类上岗必须持证；水平类分等级证明能力）；**目录外的证书，再唬人的名字也只是培训机构发的结业证明**。技能人员水平评价类资格已退出目录，转为**职业技能等级认定**（证书同样可在官方联网系统查）。

## 30 秒核验步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 先查目录：这份证属于哪一类？在不在《国家职业资格目录（2021 年版）》（人社部官网可查，**待核验**）？ |
| 2 | 查真伪：职业技能等级证/职业资格证 → [技能人才评价证书全国联网查询](http://zscx.osta.org.cn/)，输入姓名+证书编号 |
| 3 | 专技类（一建、注会、教师等）→ [中国人事考试网](http://www.cpta.com.cn/) 查成绩与证书 |
| 4 | 三步都对上，证才是"国家承认" |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 联网系统查到、信息一致 | 官方认可证书（[查询系统](http://zscx.osta.org.cn/)） |
| 查无此证 | 假证或野鸡证——培训机构发的"国际注册××师"多数查不到 |
| 目录外的证 | 不是假证但**不是国家职业资格**，不能作为持证上岗依据 |

## 常见证书归类示例（家庭速查）

| 类别 | 例子 | 含金量来源 |
| --- | --- | --- |
| **准入类**职业资格 | 法律职业资格、教师资格、执业医师、注册会计师、一级建造师 | 上岗必须持证（目录内，待核验） |
| **水平评价类**职业资格 | 经济师、翻译资格等 | 目录内，分等级证明能力 |
| **职业技能等级证书** | 健康管理师、公共营养师、电工等（原目录内技能资格转出） | 由备案评价机构认定，[联网可查](http://zscx.osta.org.cn/) |
| **从来不是国家资格** | "国际注册××师""协会认证××师"等 | 培训结业证明，无持证上岗效力 |

考出**目录内证书或技能等级证书**还可能领政府补贴：[技能提升补贴申领](/query/skill-subsidy)。
