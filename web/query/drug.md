# 药品批准文号查询 · 识别假药

::: warning 待核验
本页由 AI 依据官方平台公开信息整理，查询步骤请以平台实际页面为准；平台入口改版时以药监局官网为准。
:::

> **官方入口**：国家药品监督管理局[数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)（选"药品"分类：国产药品/进口药品/药品通用名等子库）。· 一级来源

## 速览卡

合法药品包装上都有**批准文号：国药准字 H/Z/S/B + 8 位数字**（H 化学药、Z 中药、S 生物制品、B 保健药品旧类）。文号查不到或与产品不符 = 高度怀疑假药。**用药疑虑请同时咨询医生或药师。**

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [NMPA 数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)，选"药品" |
| 2 | 选子库（国产药品/进口药品），输入"国药准字"文号或药品通用名 |
| 3 | 核对结果：**通用名、剂型、规格、生产企业、批准文号**与手里药品是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 文号与厂家完全一致 | 正常（[数据查询平台](https://www.nmpa.gov.cn/datasearch/home-index.html)） |
| 查无此文号 | 假药高度可疑，保留证据并向药监部门举报 |
| 名称一致但厂家不符 | 套号风险，警惕 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "祖传秘方/纯天然无副作用特效药" | 正规药品必须有国药准字，宣称"包治"的查证后多为假药 |
| "微信代购国外真药" | 未取得批准文号的境外药品按现行法规不得在国内销售 |
| 【本站提示】网售药品认准平台资质公示，收货核对文号 | — |
