# 身边环境查询 · 空气质量与地表水

::: warning 待核验
本页由 AI 会话信息整理并经浏览器核验入口可达；页面以总站实际发布为准。

> **官方入口**：中国环境监测总站[全国城市空气质量实时发布平台](https://air.cnemc.cn:18007/)；[国家地表水水质自动监测实时数据发布系统](https://szzdjc.cnemc.cn:8070/GJZ/Business/Publish/Main.html)。· 一级来源

## 速览卡

家里有老人、孩子、呼吸道敏感成员，出门前看一眼**官方实时空气质量**（不看商业 App 的估算值）；郊游临水而玩，查一眼**国控站点地表水水质**，心里有底。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 空气：打开[实时发布平台](https://air.cnemc.cn:18007/)，定位城市看 **AQI、首要污染物、未来预报** |
| 2 | 水：打开[水质发布系统](https://szzdjc.cnemc.cn:8070/GJZ/Business/Publish/Main.html)，按流域/站点查 **水质类别（Ⅰ～Ⅴ类）** |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| AQI 优/良 | 正常户外活动（[发布平台](https://air.cnemc.cn:18007/)） |
| AQI 轻度～中度污染 | 老人儿童减少户外剧烈活动，敏感人群戴口罩 |
| 水质 Ⅰ～Ⅲ 类 | 水质较好（注意：这是**地表水国控站点**数据，不等于自来水水质） |
