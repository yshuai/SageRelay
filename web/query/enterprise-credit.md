# 企业信用查询 · 办卡充值前先查商家底细

::: warning 待核验

> **官方入口**：市场监管总局[国家企业信用信息公示系统](http://www.gsxt.gov.cn)。· 一级来源

## 速览卡

健身房办年卡、教培充大额、装修签合同之前，先花 30 秒查企业"**底细**"：行政处罚、经营异常名录、严重违法失信名单都是公开的——一个频繁被处罚或已列入经营异常的商家，充值要三思。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[国家企业信用信息公示系统](http://www.gsxt.gov.cn) |
| 2 | 输入**企业全称**（招牌名≠企业名，看收据/合同上的公司名） |
| 3 | 重点看：**行政处罚记录、经营异常名录、严重违法失信名单、股东变更频率** |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 记录干净、状态存续 | 正常（[公示系统](http://www.gsxt.gov.cn)） |
| 列入经营异常名录 | 未按时年报或失联——充值风险高 |
| 频繁换股东/法定代表人 | 跑路前兆信号之一，大额预付慎入 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "我们是连锁大品牌，充三年最划算" | 品牌门店可能是独立注册的小公司——查**收据上的那个公司** |
