> **官方入口**：市场监管总局[缺陷产品召回技术中心](https://www.samrdprc.org.cn)（另设[消费品召回综合管理信息系统](http://xfp.samr.gov.cn/xfpww/loginPage)）。· 一级来源

## 速览卡

发现产品存在缺陷，企业要依法**召回**——召回公告全部公开。家里有婴儿用品（奶瓶、玩具、儿童床）、家电、家具的，定期查一眼召回信息，是免费的"安全体检"。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[召回技术中心官网](https://www.samrdprc.org.cn) |
| 2 | 看"召回公告"栏目，或按**产品类别/品牌/型号**检索 |
| 3 | 核对公告中的**型号、生产日期区间**与家里产品是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 在召回范围内 | 按公告联系生产者免费修理/更换/退货（[召回中心](https://www.samrdprc.org.cn)） |
| 不在范围内 | 继续正常使用；仍担心缺陷可向召回中心反馈线索 |
