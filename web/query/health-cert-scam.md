# 健康考证骗局拆解 · 健康管理师/公共营养师营销话术

::: warning 初稿待人工校验
本页由 AI 依据人社部公开政策与官方核验渠道整理；涉及证书退出目录的时间点等请以人社部文件为准（标待核验处）。

::: danger 使用须知
本页**不否定健康管理师/公共营养师证书本身**——经备案机构认定、官方可查的技能等级证书是真实有用的。本页拆解的是**围绕它的过度营销与骗局**。
:::

## 事实时间线（拆解话术的地基）

| 时间 | 事实 | 出处 |
| --- | --- | --- |
| 2017 年 | 心理咨询师退出国家职业资格目录（待核验） | 人社部目录文件 |
| 2020 年底 | **水平评价类技能人员职业资格全部退出目录**——健康管理师、公共营养师转为**职业技能等级认定**，由人社部备案的评价机构发证（待核验） | 人社部文件 |
| 现在 | 这类证书可在[技能人才评价证书全国联网查询](http://zscx.osta.org.cn/)查到——但它们**不是"国家职业资格证"** | [查询系统](http://zscx.osta.org.cn/) |

## 六大战术话术拆解

| 话术 | 拆解 |
| --- | --- |
| ①"国家取消的是旧证，我们这是**新版国家证书**" | 半真半假：证书真实存在，但性质是**技能等级证书**，不是国家职业资格——"国家证书"是刻意模糊 |
| ②"考完**挂靠**，躺着年入几万" | 健康类证书无挂靠市场，卫健系统执业不认此类证书；"挂靠费"是话术钩子 |
| ③"**政策改革前的最后一批**，再不考就报不了" | 退出目录是 2020 年完成的既定事实，"末班车"话术每年都发一遍 |
| ④"考完能**领补贴回血**，等于免费" | 补贴真实存在但有严格条件（参保 12 个月、目录/等级可查、12 个月内申领）——见[技能提升补贴](/query/skill-subsidy)；**补贴直接发个人**，"机构代收补贴"是坑 |
| ⑤"**国际认证** ACI 注册营养师，比国内的高级" | 境外/协会证书不在国家目录内，境内无执业效力 |
| ⑥"今天优惠最后一天，明天**涨价**" | 制造紧迫阻止你核验——先做完"报名前四查"再说 |

## 对照：仍然"硬"的健康类证书

| 证书 | 性质 |
| --- | --- |
| 执业医师、护士执业资格 | 国家准入类职业资格（目录内） |
| 注册营养师/注册营养技师 | 中国营养学会开展的水平评价认证——行业权威度高，但**不在国家职业资格目录内**（如实区分，待核验） |
| 健康管理师/公共营养师（技能等级） | 真实可查、对从业有证明力，但**不是**"国家资格证"、更无挂靠市场 |
