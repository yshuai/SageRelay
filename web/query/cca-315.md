# 消协智慧 315 · 扫码辨商品与消费维权

::: warning 待核验
本页由 AI 会话信息整理并经浏览器核验入口可达；功能以平台实际页面为准。
:::

> **官方入口**：中国消费者协会[全国消协智慧 315 平台](https://315.cca.org.cn)（微信/支付宝搜"消协 315"小程序，可**扫商品条码**核对信息、在线投诉）。· **二级来源**（官方指定社会组织，白名单成员）

## 速览卡

网购或收货时，用小程序**扫商品条码**，核对产品规格、型号等关键信息与官方登记是否一致，辅助识别夸大宣传；遇到消费纠纷，平台提供**在线投诉**通道，全国消协组织联动处理。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 微信/支付宝搜索"**消协 315**"小程序（或访问 [315.cca.org.cn](https://315.cca.org.cn)） |
| 2 | "扫码辨商品"：扫包装条码，核对返回的**商品名称、规格型号** |
| 3 | 有纠纷："在线投诉"提交订单凭证、聊天记录、商品照片 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 条码信息与实物一致 | 正常辅助核验（[智慧 315](https://315.cca.org.cn)） |
| 查不到该条码 | 不等于假货——新商品可能未收录；结合[召回查询](/query/recall)、[企业信用](/query/enterprise-credit)综合判断 |
| 投诉受理后 | 消协组织调解，注意保留原始凭证 |
