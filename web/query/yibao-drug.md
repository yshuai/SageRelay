# 医保药品目录查询 · 这个药能不能报

::: warning 待核验
本页由 AI 依据官方平台公开信息整理，查询步骤请以平台实际页面为准；入口改版时以国家医保局官网为准。
:::

> **官方入口**：国家医疗保障局[国家医保服务平台](https://fuwu.nhsa.gov.cn/)（"药品目录查询"模块；App 同步提供）。· 一级来源

## 速览卡

药品在不在**国家医保药品目录**、属于**甲类**（全额纳入报销）还是**乙类**（部分自付先扣），直接决定报销金额。目录每年调整（谈判新增抗癌药、慢病用药等）——查最新版，别信"这药报不了"的口头说法。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [国家医保服务平台](https://fuwu.nhsa.gov.cn/)（或 App → 药品目录查询） |
| 2 | 输入药品通用名（化学名，不用商品名） |
| 3 | 看结果：**是否在目录内、甲类/乙类、限定支付范围**（有些药只有特定病情才报） |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 目录内·甲类 | 全额纳入报销计算（[国家医保服务平台](https://fuwu.nhsa.gov.cn/)） |
| 目录内·乙类 | 先按比例自付一部分，其余纳入报销 |
| 目录内但有限定支付范围 | 符合限定病情才报，需医生诊断佐证 |
| 目录外 | 医保不报（部分商业保险可报） |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "自费药更高级，医保的不好" | 目录内不乏最新谈判药（抗癌、慢病大品种），以查询结果为准 |
