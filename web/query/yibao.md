# 医保定点机构查询 · 就医前核对报销资格

> **官方入口**：国家医疗保障局[国家医保服务平台](https://fuwu.nhsa.gov.cn/)（定点医药机构信息查询；App 内功能更全）。· 一级来源

## 速览卡

只有在**医保定点**的医院、药店就医购药，医保才能报销。异地就医还需要提前**备案**。就医前 30 秒核对，避免"看完病才发现不能报"。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [国家医保服务平台](https://fuwu.nhsa.gov.cn/)（或下载"国家医保服务平台"App） |
| 2 | 找"定点医药机构查询"，按地区/名称检索 |
| 3 | 核对：机构是否定点、等级、医保类型（职工/居民） |
| 4 | **异地就医**：在 App 内办理异地就医备案，再查就医地的定点机构 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 机构为定点且状态正常 | 可按政策报销（[国家医保服务平台](https://fuwu.nhsa.gov.cn/)） |
| 非定点 | 医保不报销该机构费用（商业保险另说） |
| 异地未备案 | 报销比例下降甚至无法直接结算——先备案再就医 |
