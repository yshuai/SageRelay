# 个税退税与专项附加扣除 · 家庭该抵的税

::: warning 待核验
本页由 AI 会话信息整理；扣除金额标准与办理细则以国家税务总局发布及个税 APP 内指引为准。
:::

> **官方入口**：**个人所得税 APP**（国家税务总局，官方应用商店）；[自然人电子税务局](https://etax.chinatax.gov.cn/)（已核验域名，站点较慢）；热线 12366。· 一级来源

## 速览卡

- **年度汇算**：每年 **3 月 1 日～6 月 30 日**，对上一年度综合所得"多退少补"——退税是家庭年度现金流事件，**不办=自动放弃**。
- **专项附加扣除**是合法少缴税的开关：七项——子女教育、继续教育、大病医疗、住房贷款利息、住房租金、**赡养老人**、3 岁以下婴幼儿照护（待核验）。
- 对本站受众的直接意义：**孩子上学、赡养父母**两项，正是大多数家庭能用上的抵税项。

## 行动清单（退税季前做完）

| 怎么做 | 出处 |
| --- | --- |
| 下载**个人所得税 APP** 注册实名，核对受雇信息（多一家"任职受雇"= 身份被冒用，立即申诉） | 个税 APP |
| 逐项填全**七项专项附加扣除**：子女教育按孩、赡养老人分摊方式与兄弟姐妹约定好（分摊一旦选定年度内不变，待核验）、房贷利息与租金**二选一** | 个税 APP 内指引 |
| 汇算时试算**年终奖计税方式**（单独计税/并入综合所得两种都点一下，哪种退税多选哪种） | APP 汇算向导 |
| 填本人**银行卡**（Ⅰ类户），退税直达卡 | 个税 APP |

## 常见漏退与驳回

| 情形 | 说明 |
| --- | --- |
| 漏填专项附加扣除 | 最常见的"少退税"原因——尤其赡养老人、房租 |
| 有兼职/劳务报酬 | 预缴率不同，汇算常能退回一部分 |
| 银行卡信息有误 | 退税失败退回，改卡重新发起 |
| 单位帮办的没选年终奖方式 | 汇算时本人可重新选择 |

## 退税季防骗（每年准时上线）

| 骗局话术 | 官方事实 |
| --- | --- |
| "您有一笔 2025 年退税待领取，点链接办理" | 官方**只通过个人所得税 APP/自然人电子税务局**办理，从不发链接、不要验证码 |
| "专业退税代办，手续费 30%" | 汇算在 APP 里**几分钟自己就能点完**，且虚假填报骗税属违法 |
| 【本站提示】收到"税务稽查"电话要转账的，直接挂断打 12366 核实 | — |
