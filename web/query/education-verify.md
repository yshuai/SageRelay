> **官方入口**：[学信网（中国高等教育学生信息网）](https://www.chsi.com.cn/)——教育部指定的学历查询唯一官网。留学学历认证走[教育部留学服务中心](https://www.cscse.edu.cn/)。· 一级来源

## 速览卡

中国高等教育学历信息**只有学信网一个官方查询口**——招聘、考公、积分落户、相亲查学历，都以学信网为准。查不到的"文凭"，无论证书做得多真都是无效学历。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[学信网](https://www.chsi.com.cn/)，注册并实人认证 |
| 2 | **查自己的**："学籍学历"栏直接看在线验证报告（可申请电子报告供单位核验） |
| 3 | **查他人的**：单位/个人凭对方授权的《教育部学历证书电子注册备案表》核验真伪 |
| 4 | 留学文凭：到[留服中心](https://www.cscse.edu.cn/)办"国（境）外学历学位认证" |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 学历信息与证书一致 | 国家承认（[学信网](https://www.chsi.com.cn/)） |
| 查无此学历 | 无效文凭——无论学校名字多正式 |
| 只有"结业证/培训班证书" | 非学历教育，不等于学历 |

## 避坑要点

| 骗局话术 | 官方事实 |
| --- | --- |
| "免试包过，一年拿本科文凭" | 国家承认学历必须参加统一招生/自考等途径，"买文凭"查不到即废纸 |
| "XX 国际大学，不需要高考" | 核对[教育部公布的全国高校名单](https://www.moe.gov.cn/)（待核验），名单外即"野鸡大学"；**留学与中外合作办学**查[教育部涉外监管网](https://jsj.moe.gov.cn/)的正规名单（已核验） |
| 【本站提示】求职者可主动出示学信网在线验证报告——正规单位只认这个 | — |
