> **官方入口**：市场监管总局[食品安全抽检公布结果查询系统](https://sac.nifdc.org.cn)（"食安查"，另有微信小程序渠道）。· 一级来源

## 速览卡

市场监管部门对市售食品做**常态化抽检**，结果全部公开——这个官方数据库收录 2014 年以来公布的合格与不合格记录。买奶粉、辅食、粮油、给老人买的保健品食品，下单前查一眼品牌，30 秒避开"上过黑名单"的批次。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开[抽检结果查询系统](https://sac.nifdc.org.cn) |
| 2 | 输入**食品名称**或**生产企业名称**（输入通用品类更全，如"婴幼儿配方乳粉"） |
| 3 | 看结果列表：抽样日期、检验项目、结论（合格/不合格） |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 该品牌多批次合格 | 正常抽检记录（[查询系统](https://sac.nifdc.org.cn)） |
| 某批次不合格 | 看不合格**项目**（菌落总数/重金属/添加剂等）与**批次日期**——同品牌其他批次不能一概而论 |
| 查无记录 | 不代表有问题，可能是未抽检到该产品 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "全网抽检零不合格才敢买" | 抽检是抽样的，查不到≠永远合格；看**自己要买的批次时段**记录 |
| 【本站提示】不合格通告会写处置措施（下架/召回）——已处置的旧批次不必恐慌 | — |
