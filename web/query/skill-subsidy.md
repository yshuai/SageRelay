# 技能提升补贴 · 考出证能领的政府钱

::: warning 待核验
本页由 AI 会话信息整理（国家社保平台入口已核验可达）；补贴标准与条件**各地有差异**，以当地规定和 12333 答复为准。
:::

> **官方入口**：[国家社会保险公共服务平台](https://si.12333.gov.cn/)（"职业技能提升补贴申领"模块）、各地人社 App/经办机构；咨询 12333。· 一级来源

## 速览卡

企业在职职工依法缴纳**失业保险**、考取**《国家职业资格目录》内**的证书（或职业技能等级证书）的，可申领**技能提升补贴**：国家基准为初级（五级）1000 元、中级（四级）1500 元、高级（三级）2000 元，**各地可上浮**（待核验）。这是"考证防坑"篇的另一半：目录内的证考下来，政府真给钱。

## 申领条件（待核验）

| 条件 | 说明 |
| --- | --- |
| 参保身份 | 企业在职职工（缴纳失业保险累计 **12 个月**及以上；部分地区放宽，含领取失业保险金人员） |
| 证书范围 | [国家职业资格目录](/query/cert-search)内证书，或官方可查的职业技能等级证书 |
| 时限 | **证书核发之日起 12 个月内**申领（待核验） |
| 次数 | 同一证书只能享受一次；每人每年享受补贴次数有上限（待核验） |

## 30 秒申领步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 先确认证书可查：[证书查询](/query/cert-search)能查到 |
| 2 | 登录[国家社保平台](https://si.12333.gov.cn/) → "职业技能提升补贴申领"，或用当地人社 App/小程序 |
| 3 | 填证书编号，系统联网核验后按当地标准发放（一般发放至社保卡金融账户或银行卡） |
| 4 | 线上办不了的：带身份证、证书到参保地失业保险经办机构办理 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 审核通过、补贴到账 | 正常（[社保平台](https://si.12333.gov.cn/)） |
| 提示"不符合条件" | 多为缴费月数不足、证书不在目录/超时限——先按提示对照，再问 12333 |
| 当地无此模块 | 部分地区走线下经办窗口，电话 12333 确认 |

## 避坑要点

| 骗局话术 | 官方事实 |
| --- | --- |
| "报我们班考完，补贴打到我们卡里再给你" | 补贴**直接发给个人**，不经过任何机构——要求代收的都是坑 |
| "包考包补贴，等于免费拿证" | 补贴有条件（参保、目录内、时限），先查自己是否符合，别为补贴反向买课 |
| 【本站提示】没有失业保险参保记录的（灵活就业、城乡居民）一般不适用本补贴——别信"人人可领" | — |
