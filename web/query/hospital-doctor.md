> **官方入口**：国家卫生健康委员会[政务服务平台"查信息"频道](https://zwfw.nhc.gov.cn/cxx/)（实测含：医卫机构查询——器官移植机构、爱婴医院名单、辅助生殖机构、产前诊断技术医疗机构；医卫人员查询——**执业医师查询**、**执业护士查询**；药物查询——基本药物目录等）。· 一级来源

## 速览卡

在中国行医的医生必须有**执业注册**，医疗机构必须有**执业许可**。就医前花 30 秒核对，能挡住绝大多数山寨医院与假医生——尤其是搜索引擎广告和"专家坐诊"传单。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [卫健委政务服务平台"查信息"](https://zwfw.nhc.gov.cn/cxx/) |
| 2 | **查医生**：选"执业医师查询"，输入姓名 + 省份（可加机构名） |
| 3 | **查机构**：按分类选机构查询（医院、辅助生殖机构、产前诊断机构等专项名单） |
| 4 | 核对结果：**执业地点、执业范围、有效状态**与对方宣称是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 医师查到，执业地点包含该机构 | 正常（[查信息频道](https://zwfw.nhc.gov.cn/cxx/)） |
| 查无此人 | 无注册执业——宣传的"专家"身份存疑 |
| 医师真实但执业地点不含该机构 | "飞刀"外聘或夸大宣传，谨慎核实 |
| 机构在专项名单（如辅助生殖）中查无 | 该机构无资质开展此类业务 |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "北京退休老专家坐诊" | 执业医师查询里查不到注册信息即无执业资格 |
| "不孕不育/疑难杂症专科" | 辅助生殖、产前诊断等有专项机构名单，名单外无资质 |
| 【本站提示】搜索引擎置顶的医疗广告与官网排场无关，资质只认注册查询 | — |
