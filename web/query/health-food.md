# 保健食品注册备案查询 · 认准蓝帽子

::: warning 待核验
本页由 AI 依据官方平台公开信息整理，查询步骤请以平台实际页面为准；入口改版时以市场监管总局官网为准。
:::

> **官方入口**：市场监管总局[特殊食品信息查询平台](http://ypzsx.gsxt.gov.cn/specialfood/#/food)（保健食品注册与备案信息查询）。· 一级来源

## 速览卡

合法保健食品包装上必有**蓝帽子标志 + 批准文号**（注册："国食健注 G/J + 4 位年代号 + 4 位顺序号"；备案："国食健备 + 4 位年代号 + 4 位顺序号"）。**没有蓝帽子就不是保健食品**——卖给老年人的"神药"绝大多数根本没有这张"身份证"。

## 30 秒查询步骤（待核验）

| 步骤 | 怎么做 |
| --- | --- |
| 1 | 打开 [特殊食品信息查询平台](http://ypzsx.gsxt.gov.cn/specialfood/#/food) |
| 2 | 选"保健食品"注册或备案库，输入产品名称或批准文号 |
| 3 | 核对结果：**产品名称、注册人/生产企业、保健功能、适宜人群**与包装宣称是否一致 |

## 结果怎么读

| 看到什么 | 说明 |
| --- | --- |
| 查到且信息一致 | 正规注册/备案保健食品（[查询平台](http://ypzsx.gsxt.gov.cn/specialfood/#/food)） |
| 查不到 | 不是保健食品——按法规不得宣称保健功能 |
| 功能宣称超出注册范围（如"治疗糖尿病"） | 违规宣传，保健食品**不得宣称疾病治疗功能** |

## 避坑要点

| 骗局话术 | 官方依据 |
| --- | --- |
| "这保健品能降压降糖替代吃药" | 保健食品不是药物，不能代替药物治疗疾病（蓝帽子产品也不允许如此宣称） |
| "会销专场/免费旅游送保健品" | 先查蓝帽子文号，再查功能是否与宣称一致 |
| 【本站提示】给老人买之前替他查一次，30 秒可能省下几千块 | — |
