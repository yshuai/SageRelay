# 首期范围：只做食养指南域，砍除软件推荐与各地常见病

最初提出六个内容方向，收敛后确认：首期（MVP）只做食养指南域——国家卫健委印发的慢性病食养指南系列（高血压、高脂血症、糖尿病 2023 年版；肥胖、高尿酸血症与痛风、慢性肾脏病 2024 年版等）与《中国居民膳食指南》，因其来源最集中、文档结构最规整、更新可追踪。

"常用工具软件"域与"全部内容取自国家权威部门"的选材原则直接冲突（没有任何国家部门发布过推荐软件清单），故砍除，改造为资质核查域：仅提供官方违规 APP 黑名单（工信部数据）查询与选型判断标准，不推荐具体软件。

"各地常见病"域因各省疾控数据公开程度参差、缺乏单一权威来源而砍除；其"地域"维度由食养指南内自带的分地区、分季节食谱承载。国标科普域列为第二期。

## Consequences

- 任何"顺便把别的域也做了"的冲动都应拒绝：多域并行会复制四套来源体系与更新机制，首期无法保证任何一套的准确性。
- 未来若重启"各地常见病"，唯一可接受的形态是"国家疾控认定的地方病/地域高发病专题"（如碘缺乏、氟中毒），数据只取中国疾控中心地方病控制中心。
