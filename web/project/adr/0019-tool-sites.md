# 白名单例外第二类：实用工具站导航（MuscleWiki 等）

用户要求收录"类似 MuscleWiki 的好用日用软件网站"。MuscleWiki、USDA FoodData Central、NutritionFacts.org 均为境外工具站，与 ADR 0002"不推荐商业品牌"红线冲突。沿用 ADR 0018 开创的显式例外机制，设立**第二类例外：实用工具站导航**，规则：

1. **双阵营物理分区**：页面分"官方阵营"（白名单内：辟谣平台、科普中国、中国天气网、国家智慧教育平台、国家图书馆——本次一并收录，均已浏览器核验）与"延伸阵营"（境外工具站），官方永远在前。
2. **收录门槛**：延伸阵营仅收**免费核心功能、无佣金无利益关联、口碑与实用性强**的工具站；付费墙产品（如 Examine.com）不收。
3. **配对义务**：每条延伸工具必须注明与官方内容的配对关系（如 MuscleWiki × 身体活动指南：官方定"练多少"，工具站补"动作怎么做"）；境外数据标准明确标注"不等于中国官方推荐量"。
4. **可下架**：出现商业化变质（加佣金、强广告）即移除。

首批：官方 5 站 + 延伸 3 站（MuscleWiki 中文界面、USDA FDC、NutritionFacts.org）。同页还完成"辟谣/科普/天气/教育/图书馆"五个官方高价值工具站的首次收录。
