# 官方查询域第二批：按生活场景扩容至 17 篇

用户提供 DeepSeek 会话整理的"国家级查询平台"清单（化妆品→农业→衣食住行→一张图系列）。处理原则与结果：

1. **AI 会话信息不直接采信**：先用浏览器逐个核验 12 个候选平台——11 个确认可达且名称属实（食品抽检 sac.nifdc.org.cn、召回中心 samrdprc.org.cn、消协智慧315 315.cca.org.cn、企业信用 gsxt.gov.cn、养老地图 yanglao.mca.gov.cn、健身一张图 js365.org.cn、旅游监管 mr.mct.gov.cn、空气 air.cnemc.cn、地表水 szzdjc.cnemc.cn、乳粉追溯 foodcredit.miit.gov.cn、化妆品备案 hzpba.nmpa.gov.cn）；农产品追溯 qsst.moa.gov.cn 返回 403（平台存在、反自动化），收录并标注。
2. **新增 9 篇查询页**：食品抽检（食安查）、溯源码（农产品+婴幼儿配方乳粉）、消费品召回、消协智慧315（**二级来源**，中消协本就在白名单）、企业信用、养老机构（养老地图）、健身设施（健身一张图）、导游/旅行社核验、环境（空气+地表水）。
3. **既有页增强**：化妆品查询页补充监管 APP、国务院客户端小程序、普通化妆品备案系统直达、抽检通告四个入口（源自该会话）。
4. **新增场景导航总览页** `/query/`：按"吃得放心/买得明白/就医用药/家有老人/动与游/环境"组织全部 17 篇查询页——场景分组来自用户会话的"衣食住行"思路，比平铺列表更贴家庭用户。
5. **候选池**（后续批次，视需求收录）：充电桩随手查（e 路畅通）、法律服务地图（12348）、公共文化云、博物馆地图、企业信用报告深度使用等。个人政务类（社保/公积金/阳光高考）暂缓——超出"家庭防坑与健康"核心定位，避免域漂移（ADR 0001 纪律）。
