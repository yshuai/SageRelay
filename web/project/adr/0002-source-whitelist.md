# 两级来源白名单与不背书红线

> **修订**：白名单部分已被 [ADR 0007](./0007-third-tier-sources.md) 扩充为三级（新增权威医疗机构与认证医生）；不背书红线与白名单之外不收的原则继续有效。

本项目唯一的核心资产是"可信"，编辑方针因此定为两级白名单：

- **一级来源**：国务院部委及直属机构（卫健委、疾控局、标准委、市场监管总局等）。
- **二级来源**：官方指定专业机构（中国营养学会、中国疾控中心、中国消费者协会），展示时必须标注来源级别。

白名单之外（医院公众号、商业健康媒体、自媒体）一律不收。把中国营养学会列为二级而非一级，是因为它是行业组织而非政府部门，但《中国居民膳食指南》在营养领域实际具有准官方地位，完全排除会损失最重要的内容。

配套红线：项目永不推荐具体商业品牌、商品、药品、保健食品；"推荐"的对象只有权威文件与判断标准。软文、带货（尤其保健品/医疗器械/药品）被永久排除——它们带来的收入远小于摧毁中立性的代价。
