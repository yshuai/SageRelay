# 国标科普域启动：以 GB 28050 营养标签为试点

ADR 0001 将国标科普域列为第二期。现在以 GB 28050《预包装食品营养标签通则》作为该域第一篇试点词条上线——理由：① 它直接支撑现有全部食养词条中"【本站提示】看营养成分表"的技能，语义上是最自然的第二域入口；② 标准文本在国家标准化全文公开系统免费可查，出处规范（链接 openstd）成立；③ 用户已确认推进数据扩域，国标科普是候选池中的第二优先。

约束不变：仍遵守 ADR 0001"一次只扩一个域"的纪律——国标科普域**试点单篇**，验证版式与更新机制后再扩（下一候选：GB 7718 预包装食品标签通则）。出处规范：链接国家标准全文公开系统的查询/阅览页，不转述标准号以外的监管字段。
