## 速览卡（一屏看完）

核心原则：**控制总能量摄入 + 吃动平衡 + 纠正不良饮食行为 + 规律作息**。（[原文·三][ob6]）

| 关键数字 | 数值 | 出处 |
| --- | --- | --- |
| 每日能量 | 平均降低 **30%～50% 或 500～1000kcal**；或男性 1200～1500kcal、女性 1000～1200kcal | [三(一)][ob7] |
| 个体化能量 | 理想体重(kg)=身高(cm)−105，×能量系数 15～35kcal/kg（卧床 15、轻活动 20～25、中活动 30～35） | [三(一)][ob7] |
| 食盐 | **≤5g/日** | [三(二)][ob8] |
| 烹调油 | **20～25g/日** | [三(二)][ob8] |
| 添加糖 | 最好 **<25g/日** | [三(二)][ob8] |
| 高能量食物 | 提供 **400kcal/100g 以上**能量的食物要少吃 | [三(二)][ob8] |
| 有氧运动 | **每周 150～300 分钟**中等强度，每周 5～7 天、至少隔天 1 次 | [三(四)][ob10] |
| 抗阻运动 | **每周 2～3 天**、隔天 1 次、每次 10～20 分钟；每周运动消耗 ≥2000kcal | [三(四)][ob10] |
| 久坐 | 静坐/伏案**每小时起身活动 3～5 分钟** | [三(四)][ob10] |
| 睡眠 | 每日 **7 小时左右**，按昼夜节律作息 | [三(四)][ob10] |
| 合理减重速度 | **每月 2～4kg**（健康减重 5%～10% 有显著获益） | [三(一)][ob7] |

## 行动清单

### 🛒 买

| 怎么做 | 出处 |
| --- | --- |
| 采购时**主动阅读营养标签**，选脂肪、碳水/糖、钠含量低的食物 | [三(二)][ob8] |
| 少买油炸食品、加工肉制品、含糖烘焙糕点、蜜饯、糖果、冰淇淋及含糖饮料 | [三(二)][ob8] |
| 多买全谷物、新鲜蔬菜等富含膳食纤维、低能量食物 | [三(二)][ob8] |
| 【本站提示】记熟"400kcal/100g 以上即高能量食物"，标签上能量一栏对一下 | [三(二)][ob8] |

### 🍳 做 / 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 减重期间饮食清淡：严格控脂肪/油、盐、添加糖 | [三(二)][ob8] |
| 多用蒸、煮、熘、水滑等烹调方式，少油煎炸 | [三(二)][ob8] |
| **减重期间严格限制饮酒**（每克酒精约 7kcal，营养素极少） | [三(二)][ob8] |
| 纠正不良饮食行为：科学选择、进餐规律、定时定量 | [三(三)][ob9] |

### 🏃 动 / 😴 睡

| 怎么做 | 出处 |
| --- | --- |
| 每周 150～300 分钟中等强度有氧 + 每周 2～3 天抗阻运动 | [三(四)][ob10] |
| 长期静坐者每小时起身活动 3～5 分钟 | [三(四)][ob10] |
| 保证每日 7 小时左右睡眠，按生物节律作息 | [三(四)][ob10] |
| 合理减重速度为每月 2～4kg，勿求速成 | [三(一)][ob7] |

### 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 食养有道：按中医辨证选择食药物质 | [三(五)][ob11] |
| 肥胖判定见附录5；运动强度系数见附录6 | [附录5][ob68]、[附录6][ob69] |

## 常见误区（原文明确告诫）

| 误区 | 原文怎么说 | 出处 |
| --- | --- | --- |
| "减重越快越好" | 合理减重速度为每月 2～4kg，过快易反弹且伤身 | [三(一)][ob7] |
| "无糖饮料随便喝" | 减重期间应严格限制饮酒、控添加糖（最好 <25g/日） | [三(二)][ob8] |
| "只运动不忌口" | 控制总能量摄入是前提：每日平均降 30%～50% 或 500～1000kcal | [三(一)][ob7] |
