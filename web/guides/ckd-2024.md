## 这份文件适合谁

成人慢性肾脏病患者及其照护者，面向不同分期（1～2 期、3～5 期、透析阶段）给出差异化建议；基层卫生工作者与营养指导人员亦可参考（[原文·前言][ck3]）。

## 速览卡（一屏看完）

**十条原则**：食物多样分期选配 → 能量充足体重合理 → 蛋白适量 → 蔬菜充足水果适量 → 少盐控油限磷控钾 → 适量饮水量出为入 → 食药物质调补有道 → 合理选择营养健康食品 → 规律进餐限酒适度运动 → 定期监测强化自我管理。（[原文·三][ck6]）

| 关键数字 | 数值 | 出处 |
| --- | --- | --- |
| 食物品种 | 每天 **≥12 种**、每周 **≥25 种** | [三(一)][ck7] |
| 低蛋白饮食（3～5 期） | 蛋白质 **0.6g/kg 理想体重/日**（理想体重=身高cm−105） | [三(一)][ck8] |
| 能量 | **30～35kcal/kg 理想体重/日**；超重肥胖者可减 500～750kcal | [三(二)][ck8] |
| BMI | **18.5～23.9**（65 岁以上 20.0～26.9） | [三(二)][ck8] |
| 主食 | 1～2 期 1/3 为粗杂粮；3～5 期用低蛋白主食（红薯、土豆、山药、粉丝等）替代部分米面 | [三(二)][ck8] |
| 优质蛋白 | 占蛋白质总量 **50% 以上** | [三(三)][ck9] |
| 红肉 | **每周 1～2 次、每次 ≤50g** | [三(三)][ck9] |
| 鸡蛋 / 奶 | 鸡蛋 **≤1 个/日**；奶 **≤300mL/日** | [三(三)][ck9] |
| 蔬菜 / 水果 | **300～500g / 200～350g**（糖尿病肾病水果 100～200g） | [三(四)][ck10] |
| 食盐 | **≤5g**；水肿者 ≤3g；严重水肿无盐膳食（钠<1000mg） | [三(五)][ck11] |
| 烹调油 | **25～40g**，脂肪供能 ≤35% | [三(五)][ck11] |
| 磷 | **800～1000mg/日** | [三(五)][ck11] |
| 饮水 | 无水肿且尿量正常 **1500～1700mL**；水肿/少尿者量出为入 | [三(六)][ck12] |

## 行动清单

### 🛒 买

| 怎么做 | 出处 |
| --- | --- |
| 植物性食物为主；3～5 期买低蛋白高能量主食（红薯、土豆、山药、藕、绿豆粉丝、小麦淀粉等） | [三(一)(二)][ck8] |
| 蛋白来源优先鱼禽类，其次大豆类，最后蛋奶畜肉 | [三(三)][ck9] |
| 不买烟熏、烧烤、腌制等过度加工食品 | [三(一)][ck7] |
| 买加工食品看标签，避免含**磷添加剂**多的食品 | [三(五)][ck11] |
| 【本站提示】"磷添加剂"常以磷酸盐字样出现在配料表（如磷酸二氢钠），见到要多留意 | [三(五)][ck11] |

### 🍳 做

| 怎么做 | 出处 |
| --- | --- |
| 少盐、少调味品；限酒或不饮酒；**限制或禁食浓肉汤、老火汤** | [三(一)][ck7] |
| 用天然味道替代盐：山楂、柠檬、辣椒、花椒、醋 | [三(五)][ck11] |
| 高钾血症者：蔬菜清水浸泡并**飞水弃汤**后进食 | [三(四)][ck10] |
| 3～5 期可适当增加亚麻籽油、紫苏籽油等富含 ω-3 的油脂作能量补充 | [三(五)][ck11] |

### 🍚 吃

| 怎么吃 | 出处 |
| --- | --- |
| 1～2 期：植物性食物为主，餐餐有蔬菜，常吃奶类大豆，适量鱼禽蛋畜肉 | [三(一)][ck8] |
| 3～5 期：低蛋白饮食（0.6g/kg 理想体重），兼顾优质蛋白 | [三(一)][ck8] |
| 5 期透析阶段仍以植物性食物为主，依情况调整动物性食物、豆类、蔬果 | [三(一)][ck8] |
| 蛋、奶含磷较高，适当控制用量 | [三(三)][ck9] |
| 3～5 期多选蛋白质少的瓜菜，适当选深色蔬果 | [三(四)][ck10] |
| 高钾血症者严格控高钾食物，每日钾 ≤2000～3000mg，避免浓肉汤、老火汤、菜汤 | [三(五)][ck11] |
| 按证型选食药物质：脾气虚山药茯苓、肾气虚黄精山药、血虚阿胶、湿热赤小豆金银花菊花、血瘀桃仁山楂 | [三(七)][ck12] |
| 因时制宜：春大枣龙眼核桃仁；夏赤小豆冬瓜绿豆薏苡仁；秋雪梨山药蜂蜜银耳；冬当归（作香辛料）、阿胶 | [三(七)][ck12] |

### 🏃 动 / 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 规律进餐定时定量，避免过度饥饿或暴饮暴食；适度运动 | [三(九)][ck14] |
| 定期营养评定与监测；发现营养风险及时膳食指导 | [三(八)][ck13]、[三(十)][ck15] |
| 必要时在临床营养师/医生指导下使用膳食营养补充剂、肾病型能量补充剂、特殊医学用途配方食品 | [三(八)][ck13] |
| 合并水肿患者的低盐膳食方案，须在专科医生指导下实施 | [三(五)][ck11] |
| 出现高钾血症及时就医 | [三(五)][ck11] |

## 常见误区（原文明确告诫）

| 误区 | 原文怎么说 | 出处 |
| --- | --- | --- |
| "肾病就要极低蛋白" | 低蛋白饮食不当易致营养不足；优质蛋白应占 50% 以上，须按分期定量 | [三(三)][ck9] |
| "喝汤养肾" | 限制或禁食浓肉汤、老火汤；高钾者避免各类菜汤肉汤 | [三(一)][ck7]、[三(五)][ck11] |
| "牛奶鸡蛋多多益善" | 蛋类和奶类含磷较高，鸡蛋每天 ≤1 个、奶 ≤300mL | [三(三)][ck9] |
| "植物蛋白不如动物蛋白" | 植物性食物更有利于减轻肾脏负担；大豆制品是蛋白和钙的重要来源 | [三(三)][ck9] |
