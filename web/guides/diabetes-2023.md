## 这份文件适合谁

成人糖尿病患者及糖尿病前期人群，以及需要为患者安排日常饮食的家庭成员；基层卫生工作者与营养指导人员亦可参考（[原文·前言][db3]）。

## 速览卡（一屏看完）

**八条原则**：食物多样、建立合理膳食习惯 → 能量适宜、控制超重肥胖和预防消瘦 → 主食定量、优选全谷物和低 GI 食物 → 积极运动 → 清淡饮食、限制饮酒 → 食养有道 → 规律进餐、合理加餐 → 自我管理、定期营养咨询。（[原文·三][db5]）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 蔬菜 | **500g**，深色蔬菜占一半以上，餐餐有蔬菜 | [三(一)][db6] |
| 蛋白质 / 碳水 / 脂肪供能比 | **15%～20% / 45%～60% / 20%～35%** | [三(二)][db7] |
| 能量参考 | 60kg 轻体力活动成年女性约 **1500～1800kcal** | [三(二)][db7] |
| 体重 | BMI **18.5～23.9**（65 岁以上可适当增加） | [三(二)][db7] |
| 减重速度 | 每月 **1～2kg**，3～6 个月减 **5%～10%** | [三(二)][db7] |
| 烹调油 | **≤25g** | [三(五)][db10] |
| 食盐 | **≤5g** | [三(五)][db10] |
| 运动 | **每周至少 5 天、每次 30～45 分钟**，中等强度占 50% 以上 | [三(四)][db10] |
| 抗阻运动 | **每周 2 次**（哑铃、俯卧撑、器械） | [三(四)][db10] |

## 行动清单

### 🛒 买

| 怎么做 | 出处 |
| --- | --- |
| 主食优先买全谷物、各种豆类等低 GI 食材 | [三(三)][db8] |
| 常买鱼、禽，适量蛋和畜肉；奶类和大豆天天有 | [三(一)][db6] |
| 少买肥肉和烟熏、烘烤、腌制等加工肉类制品 | [三(一)][db6] |
| 【本站提示】包装食品看配料表里"糖"排位和碳水含量 | [三(八)][db13] |

### 🍳 做

| 怎么做 | 出处 |
| --- | --- |
| 少油、少盐、少糖；控制油、盐、糖使用量 | [三(一)][db6]、[三(五)][db10] |
| 主食定量，学习食物计量 | [三(三)][db8] |
| 【本站提示】用生重称重法掌握自己的"一份主食"（50g 生重换算成熟重） | [三(三)][db8] |

### 🍚 吃

| 怎么吃 | 出处 |
| --- | --- |
| 餐餐有蔬菜（500g，深色过半）；水果**限量** | [三(一)][db6] |
| 减少肥肉摄入，限制酱油、鸡精、味精、咸菜、咸肉、酱菜 | [三(五)][db10] |
| 每日烹调油 25g 以内，食盐 5g 以内 | [三(五)][db10] |
| 足量饮用白水，可适量淡茶或咖啡，**不喝含糖饮料** | [三(五)][db10] |
| 规律进餐、合理加餐，促进餐后血糖稳定 | [三(七)][db12] |
| 按证型选食药物质：阴虚热盛（桑叶、决明子、莲子）/ 气阴两虚（桑椹、枸杞子、葛根）/ 阴阳两虚（山药、茯苓、肉桂） | [三(六)][db11] |

### 🏃 动

| 怎么动 | 出处 |
| --- | --- |
| **餐后运动**，每周至少 5 天、每次 30～45 分钟，中等强度（快走、骑车、乒乓球、羽毛球、慢跑、游泳）占 50% 以上 | [三(四)][db10] |
| 如无禁忌，每周 2 次抗阻运动，提高肌肉力量和耐力 | [三(四)][db10] |
| **运动前后加强血糖监测，避免低血糖** | [三(四)][db10] |
| 合并消瘦或营养不良者：在营养指导人员指导下增加膳食能量与蛋白质，结合抗阻运动增重 | [三(二)][db7] |

### 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 自我管理、定期营养咨询，提高血糖控制能力 | [三(八)][db13] |
| 能量需求因人因血糖调节而异：咨询营养指导人员制定个性化方案 | [三(二)][db7] |
| 在医师和营养指导人员指导下开展合理膳食与适量运动，防治并发症 | [三(五)][db10] |
| 老龄患者特别注意预防肌肉衰减、保持健康体重 | [三(二)][db7] |

## 常见误区（原文明确告诫）

| 误区 | 原文怎么说 | 出处 |
| --- | --- | --- |
| "糖尿病就该饿瘦" | 合并消瘦或营养不良者应**增加**膳食能量和蛋白质、结合抗阻运动增重 | [三(二)][db7] |
| "无糖食品随便吃" | 主食定量是控血糖核心，碳水供能占 45%～60% 且优选低 GI | [三(三)][db8] |
| "喝点酒降糖" | 饮酒扰乱正常膳食和用药、可致血糖波动，用胰岛素或促泌剂时低血糖风险增加 | [三(五)][db10] |
| "只控糖不控盐油" | 控制油、盐、糖三者，油 25g、盐 5g 以内 | [三(五)][db10] |
