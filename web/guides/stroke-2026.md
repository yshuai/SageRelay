## 速览卡（一屏看完）

**七条原则**：能量适宜蛋白优质、调控脂肪和碳水 → 调钾补钙多维生素、保护神经与血管 → 食物多样清淡烹饪、质地软烂易吞咽 → 适量饮水限制饮酒、合理增稠防呛咳 → 辨体辨证饮食有节 → 尽早活动全面训练 → 心理支持康养结合。（[原文·三][st8]）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 能量 | 卧床约 **20～25kcal/kg**；轻度活动约 **30kcal/kg**；中度活动约 **35kcal/kg** | [三(一)][st8] |
| 蛋白质 | 供能 **15%～20%**，至少 **1.0g/kg**；高分解代谢状态（压疮、感染）增至 **1.2～1.5g/kg** | [三(一)][st8] |
| 鱼虾类 | **每周 300～500g** | [三(一)][st8] |
| 畜禽肉 | 每天约 **50g** | [三(一)][st8] |
| 鸡蛋 | **每天 1 个** | [三(一)][st8] |
| 大豆 | **每周 100～175g** 或相当量豆制品 | [三(一)][st8] |
| 烹调油 | **≤25g**，主要来源为植物油 | [三(一)][st8] |
| 膳食纤维 | **25～30g** | [三(二)][st8] |
| 蔬菜 | **300g 以上**，深色蔬菜为主 | [三(二)][st8] |
| 食盐 | **<5g** | [三(二)][st8] |

## 行动清单

### 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 食物多样、清淡烹饪、质地软烂易吞咽 | [三(三)][st8] |
| 适量饮水、限制饮酒；吞咽障碍者**合理增稠防呛咳**（食物质地分级见附录6） | [三(四)][st8]、[附录6][st102] |
| 辨体辨证、饮食有节，按中医证型选食药物质与食养方 | [三(五)][st8]、[附录4][st86] |
| 减少酱油、鸡精等含钠调味品 | [三(二)][st8] |

### 🏃 动 / 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 尽早活动、全面训练，长期坚持助复健 | [三(六)][st8] |
| 心理支持、康养结合；四季养生以冬季为主 | [三(七)][st8] |
| 吞咽障碍先做分级筛查与评估（附录5），再确定食物质地 | [附录5][st101] |
