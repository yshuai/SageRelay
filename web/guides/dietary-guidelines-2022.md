## 这份文件适合谁

所有一般人群——它是日常"怎么吃"的总纲；具体到某一种疾病（如高血压、糖尿病），请再配合卫健委对应的食养指南词条阅读。

## 速览卡（一屏看完）

**八条准则**：① 食物多样，合理搭配 ② 吃动平衡，健康体重 ③ 多吃蔬果、奶类、全谷、大豆 ④ 适量吃鱼、禽、蛋、瘦肉 ⑤ 少盐少油，控糖限酒 ⑥ 规律进餐，足量饮水 ⑦ 会烹会选，会看标签 ⑧ 公筷分餐，杜绝浪费。（[准则一](http://dg.cnsoc.org/newslist_0402_1.htm)、[准则二](http://dg.cnsoc.org/newslist_0402_1.htm)）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 食物品种 | 至少 **12 种/日**，**25 种/周** | [准则一](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 食盐 | **<5g** | [准则五](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 烹调油 | **25～30g** | [准则五](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 添加糖 | **<50g，最好 <25g** | [准则五](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 酒精 | **≤15g/日**（任何年龄都不推荐饮酒） | [准则五](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 水 | 男 **1700mL**、女 **1500mL** | [准则六](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 身体活动 | 相当于每天 **6000 步**以上 | [准则二](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 蔬菜 / 水果 | **300～500g / 200～350g** | [准则三](http://dg.cnsoc.org/newslist_0402_1.htm) |

## 行动清单

### 🛒 买 / 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 按五大类食物搭配采购：谷薯、蔬果、鱼禽蛋肉、大豆坚果、油盐 | [准则一](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 餐餐有蔬菜、天天有水果；经常吃全谷物、大豆制品；吃各种奶制品 | [准则三](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 鱼、禽、蛋、瘦肉适量，优先鱼禽 | [准则四](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 少盐少油控糖限酒；足量饮水，不喝或少喝含糖饮料 | [准则五、六](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 【本站提示】预包装食品看营养成分表与配料表——"会看标签"是准则七 | [准则七](http://dg.cnsoc.org/newslist_0402_1.htm) |

### 🍳 做 / 🏃 动

| 怎么做 | 出处 |
| --- | --- |
| 在家做饭、学习烹饪，传承健康饮食文化 | [准则七](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 坚持日常身体活动，每周中等强度运动 150 分钟以上 | [准则二](http://dg.cnsoc.org/newslist_0402_1.htm) |
| 公筷分餐、杜绝浪费 | [准则八](http://dg.cnsoc.org/newslist_0402_1.htm) |

## 常见误区

| 误区 | 指南怎么说 | 出处 |
| --- | --- | --- |
| "水果多吃没事" | 水果 200～350g 适量，果汁不能代替鲜果 | [准则三](http://dg.cnsoc.org/newslist_0402_1.htm) |
| "喝点酒养生" | 成人每日酒精 ≤15g，且任何年龄都不推荐饮酒 | [准则五](http://dg.cnsoc.org/newslist_0402_1.htm) |
