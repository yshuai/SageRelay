## 这份文件适合谁

骨质疏松症患者，以及绝经后女性、老年人等高风险人群及其家人（[原文·前言][os5]）。

## 速览卡（一屏看完）

**七条原则**：均衡营养、摄入富含钙和维生素 D 的食物 → 荤素搭配、保证膳食蛋白质的质和量 → 食物多样、优选营养素密度高的食物 → 适度日晒、规律运动、保持健康体重 → 饮酒限量、限制含糖和高咖啡因食物 → 科学烹饪、避免高油高盐 → 选择适宜食药物质、因地因时因人施膳。（[原文·三][os7]）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 钙 | 中老年 **1000～1200mg**（可耐受上限 2000mg），膳食争取 ≥1000mg | [三(一)][os7] |
| 奶类 | **300mL 以上**（50 岁以上每天 240mL 牛奶，髋部骨折风险降低 8%）；乳糖不耐受者可选发酵乳制品 ≥300g | [三(一)][os7] |
| 蛋白质类食物 | 鱼、禽、蛋、瘦肉合计 **120～150g** | [三(二)][os8] |
| 水产品 | **每周 280～525g**（65 岁以上 280～350g） | [三(二)][os8] |
| 畜禽肉 | **每周 280～525g**（65 岁以上 280～350g） | [三(二)][os8] |
| 蛋类 | **每周 280～350g** | [三(二)][os8] |
| 大豆 | **每周 105～175g** 或相当量豆制品（65 岁以上约 105g/周） | [三(二)][os8] |
| 坚果 | **每周 50～70g** | [三(二)][os8] |
| 蔬菜 | **300～500g**（65 岁以上 300～450g），深色过半 | [三(三)][os8] |
| 水果 | **200～350g**（65 岁以上 200～300g） | [三(三)][os8] |
| 体重（老年人） | BMI **22.0～26.9** | [三(四)][os8] |

## 行动清单

### 🛒 买 / 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 每天奶类 300mL 以上（低脂亦可）；乳糖不耐受选酸奶/奶酪等发酵乳制品 | [三(一)][os7] |
| 深绿叶菜、豆制品、芝麻酱等含钙食物常上桌 | [三(一)][os7] |
| 荤素搭配，保证蛋白质"质和量"（动物蛋白+大豆蛋白） | [三(二)][os8] |
| 优选营养素密度高的食物，食物多样 | [三(三)][os8] |
| 饮酒限量；限制含糖与咖啡因含量高的食物（浓茶、浓咖啡、碳酸饮料等） | [三(五)][os8] |
| 科学烹饪，避免高油高盐 | [三(六)][os8] |

### 🌞 动 / 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| **适度日晒**促进维生素 D 合成；规律运动；保持健康体重 | [三(四)][os8] |
| 高风险人群用附录6 风险评估工具自评，及时就医查骨密度 | [附录6][os84] |
| 按证型选食药物质，因地因时因人施膳 | [三(七)][os9] |
