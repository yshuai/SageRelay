## 这份文件适合谁

肌肉量减少、肌力下降的成人（尤其老年人）及其照护者（[原文·前言][sc5]）。

## 速览卡（一屏看完）

**七条原则**：蛋白优质足量、三餐均衡分配 → 增加营养密度、膳食细软好吸收 → 按需补充营养、精准增加肌肉 → 主动多元运动、加强抗阻锻炼 → 调理脾胃为本、科学选用食药物质 → 管控基础疾病 → 监测肌少风险、早筛早诊早干预。（[原文·三][sc7]）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 蛋白质 | **1.2～1.5g/kg 体重**（肾功能正常者） | [三(一)][sc8] |
| 每餐蛋白质 | **20～25g**，三餐均衡分配 | [三(一)][sc8] |
| 鱼虾类 | **每周 300～500g** | [三(一)][sc8] |
| 鸡蛋 | **每天 1 个** | [三(一)][sc8] |
| 奶类 | **300～500mL** 或相当量奶制品 | [三(一)][sc8] |
| 大豆 | **每周约 105g** 或相当量豆制品 | [三(一)][sc8] |
| 畜禽瘦肉 | **每周 300～500g** | [三(一)][sc8] |
| 乳清蛋白补充 | **每天 20～40g**（足量蛋白和/或运动 25～30kcal/kg 者） | [三(三)][sc9] |
| 抗阻运动 | **每周 2～3 次、每次 30～60 分钟**，逐步增加负荷 | [三(四)][sc9] |
| 有氧运动 | **每周至少 3 次、每次 30 分钟以上**，同时监测心率 | [三(四)][sc9] |

## 行动清单

### 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 优质蛋白优先：鱼虾、禽畜瘦肉、蛋、奶、大豆及豆制品 | [三(一)][sc8] |
| 蛋白质三餐均衡分配，每餐 20～25g | [三(一)][sc8] |
| 增加营养密度，膳食**细软好吸收**（老年人牙口消化特点） | [三(二)][sc8] |
| 口服营养补充/乳清蛋白按需使用，全素食者也可补充乳清蛋白 | [三(三)][sc9] |
| 按证型调理脾胃，科学选用食药物质 | [三(五)][sc9] |
| 管控基础疾病（糖尿病、慢阻肺、肿瘤、肾功能不全等），合理调整方案 | [三(六)][sc9] |

### 🏃 动 / 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 抗阻运动每周 2～3 次、每次 30～60 分钟，逐步增加负荷 | [三(四)][sc9] |
| 有氧运动每周至少 3 次、每次 30 分钟以上，运动同时监测心率 | [三(四)][sc9] |
| 老年人定期做肌少症风险筛查与评估（附录5），早筛早诊早干预 | [三(七)][sc9]、[附录5][sc81] |
