## 这份文件适合谁

成人高脂血症（高胆固醇、高甘油三酯等血脂异常）人群，以及体检发现血脂偏高、心血管风险较高者及其家人；基层卫生工作者与营养指导人员亦可参考（[原文·前言][hl3]）。

## 速览卡（一屏看完）

**八条原则**：吃动平衡、保持健康体重 → 调控脂肪、少油烹饪 → 食物多样、蛋白质和膳食纤维充足 → 少盐控糖、戒烟限酒 → 因人制宜、辨证施膳 → 因时制宜、分季调理 → 因地制宜、合理搭配 → 会看慧选、适量食用食药物质。（[原文·三][hl5]）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 脂肪供能比 | **20%～25%**（按 1800～2000kcal 计，全天脂肪 40～55g） | [三(二)][hl7] |
| 烹调油 | **≤25g** | [三(二)][hl7] |
| 饱和脂肪 | <总能量 **10%**（高胆固醇血症者 <7%） | [三(二)][hl7] |
| 膳食胆固醇 | **<300mg**（高胆固醇血症者 <200mg） | [三(二)][hl7] |
| 反式脂肪酸 | <总能量 **1%**（每天 ≤2g） | [三(二)][hl7] |
| 蔬菜 | **500g**，深色蔬菜占一半以上 | [三(三)][hl8] |
| 水果 | **200～350g** | [三(三)][hl8] |
| 膳食纤维 | **25～40g**（其中水溶性 7～13g） | [三(三)][hl8] |
| 大豆蛋白 | 含 **25g** 大豆蛋白的食品 | [三(三)][hl8] |
| 食盐 | **≤5g** | [三(四)][hl8] |
| 添加糖 | <总能量 **10%**（肥胖和高甘油三酯血症者更低） | [三(四)][hl8] |
| 运动 | **每周 5～7 次、每次 30 分钟**中等及以上强度，每天至少消耗 200kcal | [三(一)][hl5] |

## 行动清单

### 🛒 买

| 怎么做 | 出处 |
| --- | --- |
| 鱼虾类、去皮禽肉、瘦肉等低脂动物蛋白优先 | [三(三)][hl8] |
| 奶类选**脱脂或低脂**牛奶 | [三(三)][hl8] |
| 少买动物脑、动物内脏等高胆固醇食物 | [三(二)][hl7] |
| 避免部分氢化植物油等含反式脂肪酸的食物 | [三(二)][hl7] |
| 【本站提示】买包装食品先看营养成分表的脂肪、钠两项 | [三(八)][hl12] |

### 🍳 做

| 怎么做 | 出处 |
| --- | --- |
| 少油烹饪：少油炸、油煎，多蒸、煮 | [三(二)][hl7] |
| 主食控制精白米面，多全谷物、杂豆、蔬菜 | [三(三)][hl8] |
| 【本站提示】用带刻度的油壶把"每日烹调油 ≤25g"落到每道菜 | [三(二)][hl7] |

### 🍚 吃

| 怎么吃 | 出处 |
| --- | --- |
| 食物每天 ≥12 种、每周 ≥25 种 | [三(三)][hl8] |
| 每日膳食纤维 25～40g：全谷物、杂豆、蔬菜 | [三(三)][hl8] |
| 每天摄入含 25g 大豆蛋白的豆制品 | [三(三)][hl8] |
| 盐每日 ≤5g；少吃酱油、鸡精、味精、咸菜、咸肉、酱菜 | [三(四)][hl8] |
| 甜食少吃，添加糖 <总能量 10% | [三(四)][hl8] |
| 完全戒烟、避免二手烟；限制饮酒 | [三(四)][hl8] |
| 按中医证型辨证施膳，总则"实则泻之、虚则补之"，食药物质见附录 | [三(五)][hl9]、[附录1·二][hl14] |
| 分季调理：春季护阳保肝（芹菜、芦笋）；长夏清利湿热（薏苡仁、赤小豆）；秋季滋阴润肺（桑椹、百合）；冬季散寒补肾（羊肉、枸杞子） | [三(六)][hl10] |
| 因地制宜，按所在地区合理搭配 | [三(七)][hl11] |

### 🏃 动

| 怎么动 | 出处 |
| --- | --- |
| 每周 5～7 次、每次 30 分钟中等及以上强度（快走、跑步、游泳、爬山、球类），每天至少消耗 200kcal | [三(一)][hl5] |
| 超重肥胖者：每日能量减少 300～500kcal，目标体重减少 **10% 以上** | [三(一)][hl5] |
| 稳定性动脉粥样硬化性心血管疾病患者：先做运动负荷试验评估安全性，循序渐进、量力而行 | [三(一)][hl5] |

### 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 定期复查血脂，把血脂、血压、血糖控制在理想水平 | [三(四)][hl8] |
| 规律作息、睡眠充足、保持情绪乐观 | [三(四)][hl8] |
| 会看慧选：看懂营养标签，适量食用食药物质 | [三(八)][hl12] |

## 常见误区（原文明确告诫）

| 误区 | 原文怎么说 | 出处 |
| --- | --- | --- |
| "只有肥肉才有脂肪" | 全天脂肪包括烹调油、动物性食品及坚果等食物中的油脂 | [三(二)][hl7] |
| "少量喝酒没关系" | 研究证明即使少量饮酒也可使高甘油三酯血症人群甘油三酯水平进一步升高 | [三(四)][hl8] |
| "血脂高就该猛运动" | 稳定性动脉粥样硬化性心血管疾病患者应先进行运动负荷试验、充分评估安全性 | [三(一)][hl5] |
| "精白米面不升血脂" | 碳水供能应占 50%～60%，适当控制精白米面、多吃膳食纤维 | [三(三)][hl8] |

## 证型与食谱怎么用

- **[附录1《食物选择》][hl13]**：分食物类别的具体选择建议；**[附录1·二][hl14]**按痰浊内阻、痰瘀互结等证型给出食药物质推荐（在限定使用范围和剂量内使用，食用方法请咨询医师、营养指导人员）。
- **[附录2《常见食物交换表》][hl15]**：同类食物等量交换。
- **[附录3《不同证型食谱示例》][hl21]**与**[附录4《不同证型食养方举例》][hl34]**：按六个证型（痰浊内阻、痰瘀互结、气滞血瘀、气虚血瘀、肝肾阴虚、脾虚湿盛）各给食谱与食养方。
