## 速览卡（一屏看完）

**七条原则**：食物多样、限制嘌呤 → 蔬奶充足、限制果糖 → 足量饮水、限制饮酒 → 科学烹饪、少食生冷 → 吃动平衡、健康体重 → 辨证辨体、因人施膳 → 因地因时、择膳相宜。（[原文·三][gt6]）

| 关键数字（每日，除注明外） | 数值 | 出处 |
| --- | --- | --- |
| 食物品种 | 每天 **≥12 种**、每周 **≥25 种** | [三(一)][gt6] |
| 全谷物 | 不低于主食量的 **30%** | [三(一)][gt6] |
| 膳食纤维 | **25～30g** | [三(一)][gt6] |
| 蔬菜 | **≥500g**，深色蔬菜（紫甘蓝、胡萝卜等）占一半以上 | [三(二)][gt7] |
| 奶及奶制品 | **300mL 以上** | [三(二)][gt7] |
| 水果 | **200～350g**（果糖限制不针对整果水果） | [三(二)][gt7] |
| 饮水 | **2000～3000mL**（心肾功能正常时），维持尿量 >2000mL | [三(三)][gt8] |
| 食盐 | **≤5g** | [三(四)][gt9] |
| 烹调油 | **25～30g** | [三(四)][gt9] |
| 减重速度 | **每周 0.5～1.0kg**；每日少摄入 250～500kcal + 运动消耗 250～500kcal | [三(五)][gt9] |
| 运动 | 有氧**每周 4～5 次、每次 30～60 分钟**（低中强度起步） | [三(五)][gt9] |

## 行动清单

### 🛒 买

| 怎么做 | 出处 |
| --- | --- |
| 以低嘌呤膳食为主，食材科学选择（嘌呤含量查附录1 表格） | [三(一)][gt6]、[附录1][gt13] |
| 买既往没诱发过痛风发作的食物；避免个人诱因食物 | [三(一)][gt6] |
| 优先菊苣、鲜百合等蔬菜，樱桃、草莓等富含维 C 的水果 | [三(二)][gt7] |
| 不买含糖饮料、鲜榨果汁、果葡糖浆、果脯蜜饯等高果糖食品 | [三(二)][gt7] |
| 不买腊制、腌制、熏制肉类（嘌呤与盐分高） | [三(四)][gt9] |
| 【本站提示】买包装饮品认准"无糖"，避开果葡糖浆配料 | [三(二)][gt7] |

### 🍳 做

| 怎么做 | 出处 |
| --- | --- |
| 少盐少油、减少调味品、清淡膳食 | [三(四)][gt9] |
| 肉类先**汆煮**后烹调、尽量不喝汤（嘌呤溶于水） | [三(四)][gt9] |
| 减少油炸、煎制、卤制 | [三(四)][gt9] |
| 【本站提示】"汆煮去嘌呤"：肉类切块冷水下锅焯 3～5 分钟弃汤再烧 | [三(四)][gt9] |

### 🍚 吃

| 怎么吃 | 出处 |
| --- | --- |
| 全谷物不低于主食量 30% | [三(一)][gt6] |
| 每天蔬菜 ≥500g、深色过半；奶 300mL 以上 | [三(二)][gt7] |
| 水果 200～350g 正常吃（水果摄入量与痛风无显著相关性） | [三(二)][gt7] |
| 白水为主，也可柠檬水、淡茶、无糖咖啡、苏打水；避免浓茶浓咖啡与生冷饮品 | [三(三)][gt8] |
| 限制饮酒：黄酒嘌呤较高、啤酒次之，白酒易致乳酸堆积；**急性发作期、药物控制不佳或慢性痛风性关节炎患者不饮酒** | [三(三)][gt8] |
| 少吃生冷食品（冰淇淋、生冷海鲜等） | [三(四)][gt9] |
| 调理脾胃食材：白扁豆、玉米须、麦芽、山药、芡实、大枣、橘皮、山楂、五指毛桃、茯苓 | [三(六)][gt10] |
| 按证型施膳：如湿浊证（常见于无症状期与间歇期）严格控制肥甘厚味、低盐膳食、避免甜腻酸涩 | [三(六)][gt10] |

### 🏃 动

| 怎么动 | 出处 |
| --- | --- |
| 低、中强度有氧为主，每周 4～5 次、每次 30～60 分钟；慢跑、走路、骑车、太极拳、八段锦、游泳 | [三(五)][gt9] |
| 适量力量和柔韧性练习；运动期间或运动后及时补水 | [三(五)][gt9] |
| **痛风性关节炎期应减少或避免运动** | [三(五)][gt9] |
| 规律作息、劳逸结合，避免疲劳 | [三(五)][gt9] |

### 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 定期监测血尿酸，遵医嘱治疗 | [三(五)][gt9] |
| 避免过度节食和减重过快（每周 0.5～1.0kg 为宜） | [三(五)][gt9] |
| 因地因时择膳相宜，结合季节与地域调整 | [三(七)][gt11] |

## 常见误区（原文明确告诫）

| 误区 | 原文怎么说 | 出处 |
| --- | --- | --- |
| "水果含果糖，痛风不能吃" | 水果的维 C、黄酮、多酚等可改变果糖影响，摄入量与痛风无显著相关性；要限的是含糖饮料、果汁、蜜饯 | [三(二)][gt7] |
| "白酒嘌呤低可以喝" | 白酒酒精度高、易使乳酸堆积抑制尿酸排泄；应限制饮酒 | [三(三)][gt8] |
| "喝肉汤补身体" | 肉类汆煮后食用、尽量不喝汤（嘌呤溶于汤水） | [三(四)][gt9] |
| "减重越快越好" | 避免过度节食和减重过快，每周 0.5～1.0kg 为宜 | [三(五)][gt9] |
| "痛着也要坚持锻炼" | 痛风性关节炎期应减少或避免运动 | [三(五)][gt9] |
