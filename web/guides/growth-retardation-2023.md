## 这份文件适合谁

生长迟缓的儿童青少年及其家长，也面向校医、营养指导人员（[原文·前言][gr3]）。**先就医明确原因，再参考食养安排日常膳食。**

## 速览卡（一屏看完）

**六条原则**：食物多样满足生长需要 → 因人因地因时食养、调理脾胃 → 合理烹调、培养健康饮食行为 → 营养教育、健康食物环境 → 适宜身体活动、关注睡眠心理 → 定期监测体格发育。（[原文·三][gr6]）

| 关键数字 | 数值 | 出处 |
| --- | --- | --- |
| 进餐结构 | 2～5 岁每天 **3 次正餐 + 2 次加餐** | [三(一)][gr6] |
| 运动 | 2～5 岁每天活动 **3 小时**（户外 ≥2 小时，中高强度累计 ≥1 小时）；6～17 岁每天累计中高强度 **≥1 小时**，每周 **3 天**强化肌肉/骨健康运动 | [三(五)][gr10] |
| 视屏 | 2～5 岁 **≤1 小时/日**；6～17 岁 **≤2 小时/日** | [三(五)][gr10] |
| 睡眠 | 2～5 岁 **10～13 小时**（含 1～2 小时午睡）；6～12 岁 **9～12 小时**；13～17 岁 **8～10 小时** | [三(五)][gr10] |
| 烹调方式 | 宜蒸、煮、炖、煨；少油炸、烧烤、腌渍 | [三(三)][gr8] |

## 行动清单

### 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 食物多样，保证能量和营养素摄入充足；三餐定时定量、饮食规律 | [三(一)][gr6] |
| 增加瘦肉、水产品、禽类、蛋类、大豆等富含优质蛋白质的食物 | [三(一)][gr7] |
| 食材切小切碎、质地软烂易消化；合理烹调以蒸煮炖煨为主 | [三(三)][gr8] |
| 按中医证型调理脾胃、因人因地因时施膳 | [三(二)][gr8] |

### 🏃 动 / 😴 睡

| 怎么做 | 出处 |
| --- | --- |
| 按年龄段保证身体活动与户外活动时长（见速览卡） | [三(五)][gr10] |
| 保证睡眠时长（见速览卡），关注心理健康 | [三(五)][gr10] |

### 🩺 测与就医 / 👨‍👩‍👧 环境

| 怎么做 | 出处 |
| --- | --- |
| 定期监测体格发育，强化膳食评估和指导 | [三(六)][gr11] |
| 开展营养教育，营造健康食物环境（家庭、学校共同参与） | [三(四)][gr9] |
| 就医排查过敏、特发性矮小、生长激素缺乏、慢性系统疾病等原因 | [二][gr4] |
