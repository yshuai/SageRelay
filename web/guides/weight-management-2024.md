## 这份文件适合谁

开展体重管理工作的医疗卫生人员，以及想科学管理体重的一般人群（[原文·前言][wm1]）。

## 速览卡（一屏看完）

内容框架：**体重的分类标准 → 体重管理相关评估 → 超重肥胖的干预和治疗 → 健康体重的管理与维持 → 特殊人群的体重管理 → 规范化体重管理流程**。（[原文·目录][wm2]）

| 关键标准 | 数值 | 出处 |
| --- | --- | --- |
| 健康体重 | BMI **18.5 ≤ BMI < 24.0** | [一][wm2] |
| 体重过低 / 超重 / 肥胖 | **<18.5 / 24.0≤BMI<28.0 / ≥28.0** | [一][wm2] |
| 减重目标 | 多数超重或轻度肥胖者：**每周减 0.5～1kg** | [三(一)][wm5] |
| 运动量 | 逐渐达到**至少 250 分钟/周**（或消耗 ≥2000kcal/周）中等至较大强度运动，分在每周 5～7 天 | [三(一)][wm26] |
| 药物治疗指征 | BMI≥28 且 3～6 个月生活方式干预减重不足 5%；或 BMI≥24 且合并高血压、高血糖等 | [三][wm9] |
| 儿童活动 | 1～5 岁**每日至少 180 分钟**多样化身体活动；学龄儿童**每日 ≥60 分钟**中等以上强度 | [三(一)][wm5] |

## 行动清单

### 🩺 了解管理路径

| 环节 | 内容 | 出处 |
| --- | --- | --- |
| 分类 | 自己的 BMI 属于哪一类（见速览卡） | [一][wm2] |
| 评估 | 病史、生活方式、体格/人体成分、医学检查、运动能力、特定人群评估 | [二][wm2] |
| 干预 | 生活方式干预（膳食模式如 5+2 间歇性能量节食等）、药物治疗、手术治疗 | [三][wm4]、[三(一)][wm5] |
| 维持 | 达标后仍需每周 200～300 分钟运动维持 | [三(一)][wm26] |

### 🍚 吃 / 🏃 动

| 怎么做 | 出处 |
| --- | --- |
| 减重膳食在医生/营养师指导下选择，含间歇性能量节食等模式（连/非连续日每周禁食 2～3 天） | [三(一)][wm6] |
| 运动循序渐进达到每周 250 分钟以上中等至较大强度 | [三(一)][wm26] |
| 儿童青少年按年龄保证每日活动量（见速览卡） | [三(一)][wm5] |
