## 速览卡

标准对学生餐的核心要求：**食物品种多样、分年龄段定量、烹调方式健康**。附录按 6～17 岁各年龄段给出每人每日食物品种及数量供给表（[原文·品种表][sm4]）。

## 行动清单：家长核对学校食谱

| 怎么做 | 出处 |
| --- | --- |
| 主食是否多样：米、面、杂粮和薯类搭配，**避免长期只提供一种主食** | [原文 P5][sm5] |
| 是否餐餐有蔬菜、每天提供水果 | [原文·品种表][sm4] |
| 蛋白质来源是否覆盖：畜禽鱼蛋奶+大豆及坚果（品种表按年龄段定量） | [原文·品种表][sm4] |
| 奶类是否每天供应 | [原文·品种表][sm4] |
| 烹调是否少盐少油少糖（去查学校公示的食谱与用盐量） | [原文·烹调要求][sm5] |

## 常见误区

| 误区 | 标准怎么说 | 出处 |
| --- | --- | --- |
| "孩子在学校吃饱就行" | 标准按年龄段规定**食物品种数与供给量**，不只是吃饱 | [原文·品种表][sm4] |
| "主食白米饭白馒头最好" | 可用杂粮或薯类部分替代米面，避免长期单一 | [原文 P5][sm5] |
