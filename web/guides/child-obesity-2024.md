## 这份文件适合谁

超重、肥胖的儿童青少年及其家长，也面向校医、营养指导人员（[原文·前言][co3]）。**儿童减重以"保证生长发育"为前提，方案请经专业评估后执行。**

## 速览卡（一屏看完）

**六条原则**：小份多样、保持合理膳食结构 → 辨证施食、因人因时因地制宜 → 良好饮食行为 → 积极身体活动 → 多方合作创造支持环境 → 定期监测科学管理体重。（[原文·三][co6]）

| 关键数字 | 数值 | 出处 |
| --- | --- | --- |
| 食物品种 | 每天 **≥12 种**、每周 **≥25 种** | [三(一)][co6] |
| 奶类 | 学龄前（2～5 岁）**350～500mL/日**；学龄（6～17 岁）**300mL 以上/日** | [三(一)][co6] |
| 三餐能量比 | 早 **25%～30%**、午 **35%～40%**、晚 **30%～35%** | [三(三)][co8] |
| 用餐时长 | 早餐约 20 分钟、午晚餐约 30 分钟；**晚 9 点后尽量不进食** | [三(三)][co8] |
| 零食供能 | 不超过每日总能量 **10%** | [三(三)][co8] |
| 身体活动 | 学龄前每天 **3 小时**（含户外 2 小时）；学龄儿童每天 **≥60 分钟**中高强度 | [三(四)][co9] |
| 肥胖儿童运动 | 从每天 20 分钟起步渐增至 **20～60 分钟**；每周 **3～4 次**、每次 20～60 分钟 | [三(四)][co9] |
| 睡眠 | 5 岁以下 **10～13h**；6～12 岁 **9～12h**；13～17 岁 **8～10h** | [三(四)][co9] |
| 视屏 | 学龄前 ≤1h/日；学龄 ≤2h/日；久坐 ≤1h/次 | [三(四)][co9] |

## 行动清单

### 🛒 买 / 🍚 吃

| 怎么做 | 出处 |
| --- | --- |
| 小份多样：每天 12 种以上食物，谷薯、蔬果、禽畜鱼蛋奶、大豆坚果都覆盖 | [三(一)][co6] |
| 增加新鲜蔬果、全谷物和杂豆比重；保证优质蛋白（鱼、禽、蛋、瘦肉、奶、大豆） | [三(一)][co6] |
| 零食首选奶类、新鲜蔬果、原味坚果；结合营养标签，少吃高油高盐高糖的过度加工食品 | [三(三)][co8] |
| **不喝含糖饮料**，足量白水少量多次 | [三(三)][co8] |
| 尽量在家就餐；在外就餐也保证蔬菜、全谷物，控油炸甜食饮料 | [三(三)][co8] |
| 肥胖儿童进餐顺序：先吃蔬菜 → 鱼禽肉蛋豆类 → 最后谷薯类 | [三(三)][co8] |
| 按证型辨证施食，因人因时因地制宜 | [三(二)][co8] |

### 🏃 动 / 😴 睡

| 怎么做 | 出处 |
| --- | --- |
| 学龄儿童每天 ≥60 分钟以有氧为主的中高强度运动（快走、骑车、游泳、球类） | [三(四)][co9] |
| 每周至少 3 天高强度/抗阻运动（跳绳、跳远、攀爬、弹力带） | [三(四)][co9] |
| 肥胖儿童在运动处方师等指导下循序渐进制订方案 | [三(四)][co9] |
| 家长与孩子共同运动，营造家庭运动氛围 | [三(四)][co9] |
| 保证睡眠时长（见速览卡），早睡早起；久坐每次 ≤1 小时 | [三(四)][co9] |
| 关注情绪性进食等心理行为问题，必要时心理干预 | [三(四)][co9] |

### 🩺 测与就医

| 怎么做 | 出处 |
| --- | --- |
| 定期监测身高体重，科学指导体重管理 | [三(六)][co11] |
| 肥胖判定按年龄段标准（见附录5） | [附录5][co38] |
| 学校、家庭、医疗机构多方合作，创造支持环境 | [三(五)][co11] |

## 常见误区（原文明确告诫）

| 误区 | 原文怎么说 | 出处 |
| --- | --- | --- |
| "孩子减肥靠饿" | 应保证平衡膳食、营养素摄入适宜，以生长发育为前提 | [三(一)][co6] |
| "零食一口不能吃" | 零食可选奶类、蔬果、原味坚果，供能 ≤10% 即可 | [三(三)][co8] |
| "吃快点没事" | 细嚼慢咽、用餐时长适宜，进餐结束立即离开餐桌 | [三(三)][co8] |
| "运动越猛越好" | 循序渐进，从每天 20 分钟起步，在专业评估指导下制订方案 | [三(四)][co9] |
