## 速览卡

指南对餐饮食品营养标识的基本要求：**真实、客观、清晰、醒目**；能量与营养素以**每份和（或）每 100g（100mL）**标示；标识可出现在**菜单、官网、官方公众号、外卖平台**等载体（[原文·标示要求][nl2]）。

## 行动清单：点餐时用官方要求"验收"

| 怎么做 | 出处 |
| --- | --- |
| 看标识是否真实清晰醒目——含糊其辞的菜单不符合指南要求 | [原文·基本要求][nl2] |
| 看能量与营养素按**每份还是每 100g** 标示，换算后再比较 | [原文·标示要求][nl2] |
| 外卖平台下单时找营养信息页面（指南允许标示在外卖平台载体） | [原文·标示要求][nl2] |
| 自助取用餐食看旁标 | [原文·标示要求][nl2] |
| 菜单若有"成年人每日能量需要约 XXXXkcal"声明，可据此估算一顿占比 | [原文·鼓励声明][nl1] |
| 【本站提示】同类菜品比较能量与钠，选双低的那份 | [原文·基本要求][nl2] |

## 与本站的关系

[GB 28050 词条](/standards/gb28050-nutrition-label)管**包装食品**的营养表，本指南管**餐饮/外卖**的营养标识——外出就餐用本页，逛超市用 GB 28050。
