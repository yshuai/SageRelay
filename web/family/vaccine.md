## 速览卡

- **免疫规划疫苗（免费）**：国家"规定动作"，**必须按时打**——入托入学要查验接种证。
- **非免疫规划疫苗（自费）**：知情、自愿原则——是家庭的选择题，不是智商税，也不是必须全打。
- 接种凭证：**预防接种证**（纸质小绿本）——终身保存，比出生证使用频率还高。

## 免疫规划程序速览（0～6 岁，简化版，待核验）

| 月龄 | 常见剂次（简记） |
| --- | --- |
| 出生 24h 内 | 乙肝第 1 剂、卡介苗 |
| 1 / 6 月龄 | 乙肝第 2 / 3 剂 |
| 2～5 月龄 | 脊灰、百白破基础免疫 |
| 6～9 月龄 | 流脑 A 群、乙脑（按当地安排） |
| 8 月龄 | 麻腮风第 1 剂 |
| 18 月龄 | 百白破加强、麻腮风第 2 剂、甲肝 |
| 2 / 3 / 4 / 6 周岁 | 乙脑加强、流脑 A+C、脊灰第 4 剂、白破加强 |

完整程序与补种规则：见《国家免疫规划疫苗儿童免疫程序及说明（2021 年版）》（[中国疾控中心](https://www.chinacdc.cn/)发布，待核验）。

## 行动清单

| 怎么做 | 出处 |
| --- | --- |
| 每次接种**带齐接种证**并当场核对记录 | 接种单位 |
| 接种记录查询：**无全国统一入口**——用当地疾控/健康云 App（如"首都疫苗服务"等），或以接种证为准 | 各地（待核验） |
| 漏种不慌：按程序说明**补种**，接种医生会给补种方案 | 2021 年版程序 |
| 想核验疫苗"出身"：中检院有**批签发**信息查询（[nifdc.org.cn](https://www.nifdc.org.cn/)，站点证书异常，入口以药监局官网为准） | 中检院 |
| 入托入学前：提前查漏补种（学校要查验接种证） | 《疫苗管理法》要求 |

## 两个极端都要躲

| 极端 | 事实 |
| --- | --- |
| "自费疫苗都是坑钱" | 非免疫规划疫苗是免疫规划的**重要补充**（如流感、水痘、肺炎等），官方态度是**知情自愿**——按家庭风险选择，而不是一票否决 |
| "全都打最贵的才安心" | 疫苗不是越贵越好；同类联苗与单苗各有取舍，问接种医生，别被营销绑架 |
| 【本站提示】看到"疫苗致病"类爆款文章：先去[辟谣平台](https://www.piyao.org.cn/)查证 | — |
