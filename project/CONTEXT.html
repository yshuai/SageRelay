本页目录

建议驿站（SageRelay） ​

第三方建设的健康与产品安全科普知识库：内容全部溯源自国家权威部门及官方指定机构发布的文件，项目本身不自称官方，页面显著声明"非官方、一切以原文为准"。目标用户为 25–60 岁的家庭决策者，典型场景：为慢病家人查官方饮食指导，为安全敏感的消费查国标要求。

名字出处：驿站是中国古代官方文书接力传递的节点——本站收录权威指南、附上出处、一站站递送给需要的人。SageRelay：Sage（权威）+ Relay（接力）。命名沿革见 ADR 0008、0009（曾用名「一枝春」）。

Language ​

定位 ​

本库: 本项目自称"建议驿站"。第三方权威来源汇编知识库，永不自称"官方"。 Avoid: 官方科普、官方平台、权威发布、一枝春（旧名）

词条: 知识库的最小单元：速览卡 + 行动清单 + 常见误区（如有） + 原文引用与溯源信息（发布机构、发布日期、原文链接、版本状态）。 Avoid: 文章、帖子、百科条目、发文字号（原文页自带，不在本站转述）

数据页: 与词条并列的内容形态：数据速览卡 + 核心数据表 + 逐项出处链接。只呈现官方统计与工具数据，不写行动清单（避免二次创作医学建议）。 Avoid: 统计文章、数据新闻

导读: 词条开头说明"这份文件适用于谁"的短文，不新增任何医学论断。

速览卡: 词条顶部的一屏摘要：关键数字与一句话结论，全部取自原文，给只需要答案的人。

行动清单: 按"买 → 做 → 吃 → 动 → 测/就医"场景组织的可执行步骤。每条逐条溯源原文，"出处"为直达原文 PDF 对应页的链接（#page=N）；语言可口语化，数字与结论不得改动。 Avoid: 建议（无出处的）、攻略、章节号纯文字（用户核验不到）

本站提示: 行动清单中显式标注的中性工具性提示（如使用限盐勺、查看配料表钠含量的方法），永不涉及医学判断，与原文内容严格区分。 Avoid: 小贴士（易与原文内容混淆）

来源 ​

一级来源: 国务院部委及直属机构发布的文件（卫健委、疾控局、标准委、市场监管总局等）。

二级来源: 官方指定专业机构发布的文件（中国营养学会、中国疾控中心、中国消费者协会），展示时必须标注来源级别。

三级来源: 权威医疗机构（三甲医院等）官方科普与经资质认证的医生科普。须资质可核、标注作者，只链接摘要不整篇转载；与一级来源冲突时以一级为准。后置启用。

白名单: 允许收录的机构总清单（一级 + 二级 + 三级），清单外一律不收。 Avoid: 权威媒体（商业媒体不在白名单内）

内容域 ​

食养指南域: 国家卫健委印发的慢性病食养指南系列与《中国居民膳食指南》。首期唯一内容域。

国标科普域: 解读消费品所执行的强制性/推荐性国家标准。第二期内容域。

资质核查域: 仅提供官方违规 APP 黑名单查询与选型判断标准，不推荐任何具体软件。 Avoid: 软件推荐、工具推荐

分地区食谱: 食养指南自带的按地区/季节划分的食谱示例，是"地域"维度的唯一权威形式。 Avoid: 各地常见病（独立域已砍除）

二期概念 ​

文献检索助手（规划中）: 二期引入的 AI 层，只返回原文出处与原句，不生成任何医学结论。 Avoid: 健康顾问、AI 医生、智能问答

版本 ​

现行 / 已废止: 词条的版本状态。新版发布后旧版归档并标注"已被 XX 年版替代"，永不删除。

红线 ​

逐条溯源: 行动清单中的每条建议必须能在官方原文中找到对应原句或数字；找不到就不写。本站提示除外，但必须显式标注。

不背书: 永不推荐具体商业品牌、商品、药品、保健食品；推荐对象只有权威文件与判断标准。 Avoid: 带货、软文、好物推荐
